# 自由探索 HUD 侧边图标化与顶部极简化布局重构计划

## 1. 任务目标
重构自由探索（Explore）模式下的 HUD 布局，由原先的“顶部大框模式”切换为“顶部极简文本条 + 左右侧轻量悬浮图标（Dock）模式”，并修正摄像机可视安全区边界，从根本上解决玩家角色走到地图顶部时被 HUD 遮挡的问题。

## 2. 核心架构与布局设计

### A. 顶部 HUD 极简化
- **高度压矮**：顶部条高度 `barH` 从 `safeTop + 68` 降到 `safeTop + 48`，减少画面遮挡。
- **视觉去框化**：去掉不透明/深色的一体式大背景面板，仅使用极简的半透明极窄条（或底边框线装饰），使其更具通透感和科幻感。
- **信息精炼**：顶部只保留以下纯文本信息，绝不承载具体任务胶囊：
  - 关卡名（左侧）：如 `训练场`
  - 玩家血条（左侧下方）：高度收窄，样式更纤细
  - 存活数（右侧）：如 `存活 7`
  - 金币数（右侧下方）：如 `金币 +12`

### B. 目标进度 dock 到左侧图标区
- **布局形式**：在屏幕左侧 `x = 16`，从 `y = safeTop + 64` 开始，垂直向下排列 3 个目标进度小卡片（圆角 4px，高 24px，宽 72px，半透明背景）。
- **内容展示**：
  - 敌人卡片：`敌 √` 或 `敌 11/12`（上限封顶）
  - 资源卡片：`资 √` 或 `资 2/3`
  - 宝箱卡片：`箱 √` 或 `箱 0/1`

### C. 下一步行动导航移至右侧图标区
- **布局形式**：悬浮在屏幕右侧 `x = canvasWidth - 16 - 72`，从 `y = safeTop + 64` 开始。
- **内容展示**：展示小型半透明青色胶囊（`宽 72px，高 24px`），文本仅保留简短行动提示，如 `清敌`、`找资源`、`开宝箱`。
- **隐藏机制**：当目标全部完成时，该右侧导航胶囊自动隐藏（或显示为绿色的 `完成`）。

### D. 屏幕边缘箭头与距离提示
- **贴边避让**：由于顶部条高度变更为 `safeTop + 48`，箭头的 Y 轴下限 `minY` 相应微调。
- **左右侧图标区避让**：为防方向箭头与左右悬浮 Dock 卡片重叠，若箭头的目标投影坐标在左右侧卡片范围内，则将其纵向避让推至更下方。

### E. 彻底解决玩家顶部遮挡问题
- **世界边界动态约束**：在 `ExploreScene.ts` 的 `clampPlayer` 限制中，自由探索模式下玩家的 `minY` 不再是默认的 `radius`，而是强制约束为 `minY = safeTop + 48 + 32`（即安全顶部高度 + 32px 的安全边距缓冲区，约为 100~120px）。
- **无抖动不露黑边**：该约束通过原生 `clampPlayer` 边界移动限制执行，玩家在世界坐标上无法走到最顶端 HUD 的背后，直接在屏幕呈现上实现了“不被 HUD 遮挡”，且绝对不影响相机的平滑跟随时产生抖动或露出地图黑边。

## 3. 拟修改文件

- `src/ui/BattleUI.ts`：重构顶部文本条、绘制左右侧悬浮 Dock、调整边缘箭头避让。
- `src/explore/ExploreScene.ts`：修改 `clampPlayer` 中的 `minY` 边界约束。
- `src/debug/ExploreTestProbe.ts`：添加并导出 `hudMode`、`hudHeight`、`hudTopTextOnly`、`leftObjectiveDockVisible`、`rightGuideDockVisible`、`playerScreenSafeTop`、`playerScreenY`、`playerOccludedByHud` 等字段。
- `test/exploreTask16_2.test.ts` [NEW]：新写针对本重构版的专门单元与集成测试。

## 4. 风险点与应对
- **测试用例回退风险**：任务 16/16.1 原有测试用例在对 HUD 状态校验时可能会检查 `hudHeight: 68` 等旧数值。需要将新模式与旧模式进行兼容，在 `hudMode: 'edge-minimal'` 下更新字段值以防止已有单元测试挂掉，或者为已有单测适配新字段。
