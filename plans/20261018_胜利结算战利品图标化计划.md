# 胜利结算战利品图标化

日期：2026-10-18。

## 可观察成功标准

- 结算中的金币、零件、强化石、装备、符文和自选奖励均以真实图标卡展示；数量、符文等级与品质边框可直接辨认。
- 页面去掉掉落名称长列表，保留关卡、星级和简短状态；点击图标查看名字与实际属性，自选仍进入原部件选择。
- 奖励多时区域独立滚动，不遮挡返回/再战；卡片短演出增强获得感，不增加领取或保存次数。
- 正式发奖与失败回滚逻辑不变；保存失败不呈现虚假入库物品，失败结算无永久战利品。
- 隔离存档验证所有类型、真实鼠标操作、详情返回、长列表、失败保存和自选入口，实机 GPU 截图核查版面。

## 实施范围

1. 复用现有 EquipmentArt、RuneArt 和 UiArt，建立独立 settlement_ui.gd 承载结算展示；main 只委托展示，保留 settle/暂停/重复结算保护。
2. 货币和同种材料合并数量，装备/符文按实际 UID 独立展示，不以模板代替实例。
3. 主代理实现界面，子代理只新增专项测试和截图脚本，避免同文件修改冲突。
4. 跑相关结算/界面/符文回归和 GPU 图形输入检查，完成成果及开发日记。所有运行使用仓库 tmp 隔离档。

不改奖励掉率、数值、存档格式，不新建美术资源，不提交或发布。原未提交内容全部保留。
