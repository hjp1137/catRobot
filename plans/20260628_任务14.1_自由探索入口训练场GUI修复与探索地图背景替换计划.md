# 任务14.1：自由探索入口训练场GUI修复与探索地图背景替换计划

## 本任务目标
- 修复 devtools “自由探索”入口真实进入 `explore_training`，与固定屏 `1-1` 战斗测试入口分离。
- 让自由探索首屏 HUD 明确显示“训练场 / 自由探索”，并避免串用固定关卡标题。
- 将探索主背景固定为程序化训练场地图，禁止使用旧大机甲人物背景作为地图。

## 当前截图暴露的问题
- 真实 GUI 仍像固定屏战斗，背景、HUD 和镜头滚动感不清晰。
- 玩家出生位置偏左，摄像机初始跟随效果不明显。
- 训练场地图需要更强地面、边界、分区和装饰识别度。

## 拟修复模块
- `src/core/GameManager.ts`、`src/ui/MainUI.ts`：入口切换与快速入口隔离。
- `src/explore/ExploreScene.ts`、`src/explore/ExploreRenderer.ts`、`src/explore/ExploreMapRenderer.ts`：探索状态、地图和镜头表现。
- `src/ui/BattleUI.ts`、`src/debug/ExploreTestProbe.ts`、`test/exploreTask14.test.ts`：HUD 数据、探针和回归断言。

## 背景替换方案
- 自由探索只绘制 `training_ground` 程序化地图，不调用 `main_bg` 或固定屏 `BackgroundRenderer`。
- 地图增强基础地面纹理、分区地板、发光线路、边界围栏、废料箱、能量柱、残骸与区域编号。

## 摄像机修复方案
- 调整出生点到地图中部附近，并在 `start()` 后立即按玩家位置初始化摄像机。
- 保持玩家、敌人、弹道、伤害数字、掉落物使用世界坐标，HUD、技能按钮、摇杆使用屏幕坐标。

## 测试计划
- 扩展任务14测试：入口状态、HUD 标题、背景不调用 `main_bg`、地图装饰、摄像机初始跟随、固定屏入口不受影响。
- 执行 `npm run typecheck`、`npm run build`、任务指定单测与 `npm test`。

## 风险点
- `BattleUI` 为固定屏与探索共用，修改 HUD 时需避免影响波次战斗。
- `ExploreRenderer` 复用攻击范围绘制，需确认不会引入固定屏背景资源。
