# 任务20 训练场 P0 首版可见美术素材替换与 GUI 效果验证计划

## 目标
让 `training_ground_v1` 不再只是 Manifest 槽位，完成一批 P0 首版可见样张、资源包启用、渲染层接入和可复核测试。

## 任务19 GUI 无明显变化原因
任务19主要完成资源架构、目录槽位和 fallback/virtual 自检链路。训练场包当时未启用，且除主角待机样例外缺少成批实体图，运行时仍主要回退到旧资源和程序化绘制。

## 本次 physical 资源范围
- 主角：`player.mechaCat.idle`、`player.mechaCat.move`、`player.mechaCat.attack`。
- 普通敌人：`enemy.scrapMouse.normal`、`enemy.scrapBug.normal`、`enemy.droneEye.normal`。
- 精英敌人：`enemy.scrapGuard.elite`。
- 地图：`map.trainingGround.floor`、`map.trainingGround.line`、`map.trainingGround.boundary`、`map.trainingGround.zoneMark`。
- P1 可见增强：`ui.skill.shield`、`ui.skill.cannon`。

## 启用方案
保持 `ART_PACKS.training_ground_v1.enabled = true`，并让已落地图片移除 `virtual`。旧基础 Key 通过 Resolver/ResourceManager 局部重定向到训练场包路径，未落地资源继续 fallback。

## 渲染接入方案
- `MechaRenderer` 继续使用 `player_mecha` 图片资源。
- `Chapter2EnemyRenderer` 需要让普通与精英敌人在资源加载成功时也优先使用图片，不再只对非默认变体用贴图。
- `ExploreMapRenderer` 需要在自由探索训练场中优先绘制 `main_bg` 对应的训练场地面图，再叠加保留区域线与标识。
- 固定屏战斗背景使用训练场地面图，并保留深色遮罩以弱化旧巨型机甲背景影响。

## 测试计划
- 先补失败测试：P0 physical 资源必须有真实 PNG 尺寸，ResourceManager 必须指向训练场包，普通/精英敌人和自由探索地图必须绘制训练场图片。
- 通过后运行：`npm run typecheck`、`npm run build`、`npm run check:art`、`npm test`。
