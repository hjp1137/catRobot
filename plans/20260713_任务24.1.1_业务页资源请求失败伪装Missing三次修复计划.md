# 任务24.1.1 业务页资源请求失败伪装 Missing 三次修复计划

## 1. 现象
- Chrome 当前页已发出 `/api/content/resources/:artKey` 请求。
- 页面控制台出现 `AxiosError`，Vue mounted hook 被打断。
- UI 仍显示 `missing`，未区分资源真实缺失与请求失败。

## 2. 根因判断
- 后端 3100 资源接口返回 `physical` 摘要，资源数据和文件存在。
- 前端请求失败后被组件 catch 吞掉，回落到空 resource。
- 空 resource 在 `ArtResourceThumb`/`ArtResourceField` 中被统一渲染成 `missing`，造成误判。

## 3. 修复
- API 客户端增加 401 响应处理：清除本地 token 并跳转登录页。
- 业务页资源列表加载失败时不再打断页面 mounted hook。
- 资源字段和缩略图组件区分 `missing`、加载中、加载失败。
- 请求失败显示“加载失败”，不再展示为资源 missing。

## 4. 验证
- 增加前端回归测试覆盖 401 处理和资源加载失败文案。
- 复跑管理端测试、typecheck、build。
- 使用 Chrome 当前页刷新验证不再将接口失败显示为 missing。
