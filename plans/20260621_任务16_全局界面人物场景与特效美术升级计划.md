# 任务16：全局界面、人物、场景与特效美术升级计划

## 1. 目标与边界
在现有原生微信小游戏 Canvas 2D 架构上增量升级全局视觉，复用 `Theme`、`DrawUtils`、`UIWidgets`、`ResourceManager` 和各 Renderer，不重写玩法系统。
- 覆盖主界面、章节、关卡、关卡介绍、战斗、技能养成、装备和结算界面。
- 补齐三章场景、玩家、配置中全部敌人与 Boss、道具、装备、符文、技能、状态和交互反馈素材。
- 素材标记为“内部原型可替换素材”，保持单张和总体积在规范范围内。
- 本次任务不提前实施新手引导和数值调优（任务17），不实施封板（任务18）。

## 3. 详细设计方案

### 3.1 扩展视觉令牌和通用组件
在 `src/ui/UIWidgets.ts` 中集中实现和扩展通用绘制组件，统一视觉风格，消除重复硬编码，并保持既有点击语义和业务流程完全兼容。

1. **统一按钮 `drawButton`**
   - 增加 `time?: number` 参数，引入微弱的呼吸高亮动画（通过 `breathe(time)` 或 `Math.sin`）。
   - 按钮主体使用圆角矩形（`Theme.radius.md`）。
   - 绘制投影（偏移 2, 3，使用 `rgba(0,0,0,0.3)` 阴影色）。
   - 按钮渐变色：从自定义颜色或 Theme 对应的主色，向更深的 `Theme.color.bgPanel` 或更深颜色过渡，增加质感。
   - 统一处理 `disabled` 状态：背景使用 `Theme.color.grayDark`，文字使用 `Theme.color.gray`。

2. **高级面板 `drawPanel`**
   - 接收 `(c: ICanvas2D, x, y, w, h, opts?: { border?: string; bg?: string \| IGradient; radius?: number; borderSize?: number })`。
   - 统一渲染带圆角（默认 `Theme.radius.lg`）、发光描边、深色渐变背景的高级科技面板。

3. **高级标题 `drawTitle`**
   - 接收 `(c: ICanvas2D, title: string, subtitle?: string, opts?: { x?: number; y?: number; w?: number; align?: CanvasTextAlign })` |
   - 绘制金色主标题、青色副标题、两侧科技装饰线以及小星星点缀。

4. **资源条 `drawResourceHeader`**
   - 统一在 `SkillPanelUI`、`EquipmentPanelUI` 头部以胶囊半透明背景展示金币、零件、强化石，优先用 `drawImage` 绘制图标，失败用圆形兜底。

5. **状态标签 `drawBadge`**
   - 统一用于“已装备”、“已激活”、“锁定”等状态标识。

### 3.2 补齐资产库与资源清单

新登记资源及兜底方案：
1. **背景图**
   - `sewer_bg` (`assets/sewer_bg.png`)：下水道背景。
2. **敌人/Boss**
   - `enemy_elite_mouse` (`assets/enemy_elite_mouse.png`)：强化机械鼠。
   - `enemy_rat_king` (`assets/enemy_rat_king.png`)：第一章 Boss 机械鼠王。
   - `enemy_beetle` (`assets/enemy_beetle.png`)：第二章普通甲虫。
   - `enemy_toxic` (`assets/enemy_toxic.png`)：第二章普通毒虫。
   - `enemy_elite_toxic` (`assets/enemy_elite_toxic.png`)：第二章精英毒虫。
   - `enemy_pollution_queen` (`assets/enemy_pollution_queen.png`)：第二章 Boss 虫后。
3. **装备**
   - `equip_rusty_claw` / `equip_neon_blaster` / `equip_starcore_cannon`
   - `equip_patched_armor` / `equip_alloy_armor` / `equip_sewer_guard`
   - `equip_small_core` / `equip_neon_core` / `equip_starcore_fragment`

### 3.3 替换细节与逻辑接入
1. **`BackgroundRenderer.ts` 接入背景图**
   - 修改 `drawSewerBackground`：若 `sewer_bg` 已加载，直接绘制；否则执行现有的波纹与霓虹管线绘制。
   - 对 `drawTrainingBackground` 同步改造（接入 `main_bg`），统一分发。
2. **`Chapter2EnemyRenderer.ts` 与 `EnemyRenderer.ts` 接入敌人图片**
   - 优先查找对应 variant 的图片资源（如 `enemy_beetle`、`enemy_toxic` 等），若 `isLoaded` 且存在，通过 `drawImage` 绘制；否则执行 Canvas 原有兜底函数。
3. **`EquipmentPanelUI.ts` 与 `ResultUI.ts` 接入装备与符文图片**
   - 不再只对第三章熔岩装备和避火符文特殊映射，而是根据配置 ID 统一匹配对应的图片资源键。
4. **`BattleUI.ts` 接入 `status_poison` 毒液状态图标**
   - 参考 `status_burn`，若加载成功绘制图标，否则绿色文字兜底。

### 3.4 适配与多分辨率验证
- 支持 `320×568`、`375×667`、`414×896` 及 DPR 1/2/3。
- 所有 UI 元素使用相对或布局计算坐标，关键文本、按钮、弹窗在各分辨率下居中或合理对齐，绝不超出边界，且交互热区与视觉位置严格保持一致。
