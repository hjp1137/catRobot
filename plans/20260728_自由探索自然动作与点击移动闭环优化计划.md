# 自由探索自然动作与点击移动闭环优化计划

## 根因

- 角色和敌人额外叠加 `scaleX/scaleY` 压缩回弹，造成周期性缩小、放大和坐标平移感。
- 敌人移动渲染强制固定使用单张 `moveArtKey`，没有播放动作片段。
- 现有机械鼠两张移动帧并非同一套造型，直接切换会产生严重闪变。
- 探索角色在资源未命中时仍允许回退旧通用机甲，无法彻底排除旧橙红图瞬时出现。
- 触控只支持持续拖动摇杆，没有点击地面后持续行走的目标状态。

## 修复

1. 先补失败测试：动作姿态不得缩放，敌人必须交替同系列帧，探索角色任何状态不得回退旧攻击图。
2. 以当前深灰橙色机械鼠为参考生成同造型交替落脚帧；候选图片必须先通过后台创建 Art Version、绑定既有 Art Key，再进入 Animation Clip。
3. 删除探索层程序化缩放、旋转和弹跳，动作只由一致的序列帧表达。
4. 通过后台资源版本替换和动作编排统一白色角色素材；游戏端只消费发布快照，不写死 Art Key 或物理路径。
5. 增加点击地面移动：目标转为世界坐标，抵达或受阻停止；摇杆输入立即取消自动移动。
6. 技能、退出和确认按钮优先消费点击，避免穿透触发移动。
7. 经后台校验并创建新 Release，同步 Art/Animation/Content 发布快照后，再完成专项、全量、资源、动画及微信开发者工具实测。
8. 修复美术资源页对公共资源 API 返回形态的二次解包，确保后台配置页面能正常展示刚发布的版本。

## 验收

- 角色与敌人移动时不再周期性缩小，均能看到一致造型的交替步态。
- 自由探索全过程不出现旧橙红角色。
- 点击可通行地面后角色自动走到目标；摇杆可随时接管。
- 所有新增或替换动作帧均存在后台 Art Version 与发布记录，运行时代码不包含素材键映射。
