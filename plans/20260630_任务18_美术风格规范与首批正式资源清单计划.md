# 美术风格规范与首批正式资源清单计划

## 1. 任务目标
确定《喵喵机甲》的整体美术风格规范与资源分类标准，设计 P0 / P1 / P2 优先级的首批正式美术替换清单；并在 `ART_MANIFEST` 与 `ART_PACKS` 中配置预留相关的 Key 和新资源包 `'training_ground_v1'`，通过 `virtual: true` 保证自检脚本与自动化测试绿灯。

## 2. 规范与清单文档设计

### A. 美术风格规范文档 (`docs/20260630_喵喵机甲_美术风格规范.md`)
- 风格定位：明确以“Q版机甲猫 + 赛博训练场 + 轻度废土科幻 + 微信小游戏高可读性”为主基调。
- 色彩主调：限定科幻青蓝/黑为主背景，暖金色与警示红作为强调对比色。
- 比例视角：明确自由探索模式为俯视/斜俯视视角，限定主角与普通/精英怪物的视觉尺寸比例关系。
- 细节笔触：高可读性线条，简单发光与高亮轮廓，剔除低效碎纹理。

### B. 首批正式资源清单文档 (`docs/20260630_喵喵机甲_首批正式美术资源清单.md`)
- 分级整理 P0 / P1 / P2 美术素材名单。
- 每一个清单项在文档中均以表格形式完整展现，明确：
  - 资源类别与用途
  - Manifest Key
  - 建议物理文件名
  - 推荐尺寸
  - 是否有透明背景要求
  - 优先级与当前状态
  - 是否标记为 virtual。
- 规划统一的资源包目录，新增 `"training_ground_v1"`（训练场正式资源包 v1）目录占位。

## 3. 代码与配置预留

- **预留 Key & Manifest**：
  - 在 `src/assets/ArtResourceKeys.ts` 中追加首批正式资源 Key 类型；
  - 在 `src/assets/ArtManifest.ts` 中注册这些 Key 配置，将 `pack` 设为 `'training_ground_v1'`，且均加上 `virtual: true` 与 `fallback: 'placeholder.image'`。
- **预留资源包**：
  - 在 `ART_PACKS` 中追加 `training_ground_v1: { name: '训练场正式资源包 v1', enabled: false }`，默认状态为 `false`。

## 5. 风险点与应对
- **资源路径缺失报错**：新预留的 Key 指向尚未生成的文件。
  - **应对**：必须在 `ART_MANIFEST` 中显式设置 `virtual: true`，这样资源完整性检查命令 `npm run check:art` 会自动跳过该物理文件校验，确保 100% 绿灯过关。
