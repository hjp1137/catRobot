## 六、StatusEffect（新增 src/player/StatusEffect.ts）
```ts
type StatusEffectType = 'poison'
interface RuntimeStatusEffect { type, remaining, tickInterval, tickTimer, damagePerTick }
class StatusEffectManager {
  applyPoison(duration, damagePerTick)  // 重复命中取较高 damagePerTick + 刷新 duration
  update(dt, player)  // tick 计时 → player.takeDamage(damagePerTick)
  clear()
  has(type)
}
```
毒液伤害走 player.takeDamage（自动受护盾减免）。玩家死亡/战斗结束 clear。
