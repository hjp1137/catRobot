# 任务8：第二章 Boss 关机制与污染核心战斗 方案

## 一、定位
2-5 升级为第二章 Boss 关 + 污染核心虫后 Boss（毒液领域/污染喷发/召唤）+ 第二章完成提示 + 毒液 UI 强化。复用任务4 BossSkill 架构思路，新增独立 PollutionBossSkill。不破坏任务1~7 的 200 测试。

## 二、EnemyConfig 新增污染核心虫后
variant 加 'chapter2_boss'。
```ts
pollution_core_queen: { maxHp 360, atk 8, speed 18, interval 1.8, r 38, variant chapter2_boss,
  poisonOnHit: { duration 3, damagePerTick 4, tickInterval 1 } }
```

## 三、2-5 重构4波 Boss 关
isBossStage=true，waves 4 波：
- w1 污染虫群：4 甲虫
- w2 毒液扩散：4 毒液虫
- w3 精英护卫：1 精英毒液虫 + 2 毒液虫
- w4 虫后登场：1 污染核心虫后
奖励 720/72，power 700

## 四、PollutionBossSkill（新增 src/battle/PollutionBossSkill.ts）
独立类，与 BossSkill(鼠王) 并列。EnemyMouse 按 variant 选择挂哪个。
三机制：
1. 毒液领域 ToxicField：idle(7s)→warning(1s,紫绿预警圈,不伤)→active(4s,玩家在 boss 半径110内每秒受4伤害,走takeDamage受护盾减免)→cooldown
2. 污染喷发 PollutionEruption：锁定技能开始时玩家位置，预警1.2s→爆发半径65内一次14伤害+poison(3s,3/tick)
3. 召唤：hp<50% 召唤2毒液虫（onSummon回调），每场1次
状态机各自独立计时。boss dead → disable。
通过 getRenderStates 暴露：fieldState(预警/active)、eruptionState(预警/爆发) 给 render。

## 五、EnemyMouse 接入 BossSkill 分发
- 现 bossSkill 字段类型 BossSkill（鼠王专用）。改为通用 bossSkill: BossSkill | PollutionBossSkill | null
- variant==='boss' → BossSkill；'chapter2_boss' → PollutionBossSkill
- update 推进对应 skill；render 取 renderState
- 用接口 IBossSkillController 统一 { update, disable, getRenderStates }，便于 BattleManager 遍历

## 六、ProgressManager chapterCompleted 通用化
当前 chapterCompleted: boolean（仅1-5）。改为同时支持2-5：
- ClearResult.chapterCompleted: boolean（保留，1-5或2-5首次通关=true）
- 加 LAST_CHAPTER2_STAGE_ID='2-5'；applyClear 判定 stage.id===LAST_CHAPTER1||LAST_CHAPTER2 且 firstClear
- ResultUI 按 stageId 显示对应章节完成文案（1-5→第一章，2-5→第二章）

## 七、render/UI
- Chapter2BossRenderer（虫后：大体型+紫绿核心+腹部能量囊+多足+毒液罐+复合眼+污染光晕）
