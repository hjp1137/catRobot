## 2. 编码前实查
1. `content-store/published/content.snapshot.json` 当前为 `R000007`，不包含 `animationClips` 字段。
2. 当前存在 `content-store/published/animation-manifest.snapshot.json`，同标记 `R000007`，含2个任务25样例 Clip。
3. 游戏构建经 `src/content/generated/contentSnapshot.ts`、`LocalContentRepository`、`AnimationManifestRepository`读取发布快照；旧内容快照缺 `animationClips` 时当前会回退 `src/content/data/animations.ts` 内置样例。
4. 内置动画样例定义在 `src/content/data/animations.ts`，同时被本地默认内容、seed脚本和旧快照兜底引用。
5. 数据库 seed 位于 `server/prisma/seed.ts`，只在执行 seed 时写入草稿 MySQL，不应被正式小游戏运行时直接读取。
6. `FrameSequencePlayer` 当前支持 `loop`、`once`、`hold-last-frame`，但缺单帧前进/后退、速度倍率、明确完成状态接口。
7. 敌人受击真实触发在 `PlayerMecha.resolveProjectileHit()`、`useSkill()` 后调用 `EnemyMouse.takeDamage()` 与 `registerHit()`。
8. 主角受击真实触发在 `EnemyMouse.update()`、Boss技能、毒/火状态等路径调用 `PlayerMecha.takeDamage()`。
9. 当前状态恢复依赖 `hitFlash` 递减后重新解析状态，未按 hit Clip 结束回调恢复。
10. 管理端 `AnimationClipsView` 已有列表、编辑、播放预览、上移/下移、帧时长、播放模式字段，缺暂停/恢复/重置/单帧/速度/首尾移动/警告证明。
11. `SceneArtPreview` 已展示背景、主角、敌人、动作切换和播放开关，缺草稿/已发布切换、重置、缩放、速度和来源信息。
12. `npm --prefix server run content:db:status` 显示远程 MySQL `cat_robot` 4个 migration，schema up to date。

## 3. 修复策略
- 先补专项红灯测试：旧快照不读内置动画、动画快照缺失/损坏回退静态、播放器三模式与单帧控制、敌人/主角 hit 恢复。
- 正式运行时只读取已发布 Animation Manifest；旧内容快照缺动画时 `animationClips` 返回空数组，不再隐式使用内置样例。
- 保留 `src/content/data/animations.ts` 作为 seed、测试和显式本地默认内容来源，不参与发布快照兜底。
- 为 hit 增加最小状态保持与恢复机制：受击重启动画，死亡优先，结束后按移动/攻击/idle规则恢复；对象死亡或清理后不触发过期回调。
- 补后台动作预览控制和场景预览控制，保持现有 Ant Design Vue 页面结构。
