# 任务24.1 喵喵机甲美术资源可视化浏览业务页面图片预览与统一替换交互修复计划

## 1. 实查结论
- 当前管理端实际目录为 `admin/apps/web-antd`，是 Vue3、Ant Design Vue、Pinia、Vue Router、Vite 子应用。
- `admin/package.json` 与子应用均标注 `vbenAdminTargetVersion=5.7.0`，但当前不是完整 Vben 工程骨架，实际页面为本仓库自建 Ant Design Vue 管理端。
- `/content/resources` 由 `ResourcesView.vue` 实现，已有列表、缩略图加载、详情抽屉、版本历史、草稿/发布对比、上传版本、设草稿、删除未发布版本。
- `ArtResourceSelector.vue` 已能列出 Art Key、缩略图、资源包、状态、草稿/发布版本，并禁选 missing/invalid。
- 后端图片访问为 `GET /content/resources/:artKey/versions/:versionId/thumbnail|preview`，经 `JwtAuthGuard`，服务端用安全相对路径解析，不暴露服务器绝对路径。
- 现有数据结构包含 `physical`、`virtual`、`fallback`、`missing`，版本状态包含 `valid`、`warning`、`invalid`、`published`、`archived`；未见独立 `invalid` 资源状态枚举，异常主要落在版本状态。
- 敌人、背景、主角共用 `EntityListView.vue`，路由为 `/content/enemies`、`/content/backgrounds`、`/content/heroes`；关卡为 `/content/stages`，同页展示，但当前缺少列表图片预览。
- 删除内容引用保护在 `ContentCrudService.references/remove`；删除资源版本保护在 `ArtResourcesService.removeDraftVersion`；`ArtResourcesController.references` 仍是占位返回。
- 远程 MySQL 状态：`npm --prefix server run content:db:status` 已显示 `cat_robot` schema up to date，现有 3 个 migration。
- 可复用组件现状：选择器、资源详情对比和缩略图样式已存在，但没有公共 `ArtResourceField`/图库卡片；需抽取复用，避免各页面复制逻辑。

## 2. 根因
- 任务24完成了资源版本与缩略图能力，但资源页默认仍是表格，业务页面列表只展示 ID、名称、版本、更新时间。
- 编辑抽屉虽然用选择器替代了纯文本，但字段本身仍不是资源卡片，缺少当前图、查看原图、替换当前、解除绑定等清晰操作。
- 关卡页复用通用列表，尚未把背景、主角、敌人引用解析成可视化摘要。

## 3. 实施步骤
- 新增管理端资源可视化工具模块与公共组件，统一缩略图 URL、预览候选、草稿变更、状态颜色、字段定义。
- 先补 Vitest 失败测试，覆盖默认图库、资源字段操作语义、业务页预览候选优先级、Missing/Invalid 展示规则。
- 将 `/content/resources` 改为默认图库模式，保留表格视图和筛选条件，详情抽屉继续复用任务24版本能力。
- 将 `EntityListView` 接入资源摘要缓存，敌人、背景、主角、关卡列表新增预览列。
- 将编辑抽屉资源字段替换为公共可视化资源字段，保留 `ArtResourceSelector`，明确选择已有、上传新资源、替换当前图片、查看版本、解除绑定。
- 后端只在必要时补引用聚合接口，不改变 Prisma 模型、不新增 migration、不修改发布快照。

## 4. 验证计划
- 管理端：`pnpm --dir admin/apps/web-antd test`、`typecheck`、`build`。
- 根项目：`npm run typecheck`、`npm run build`、`npm test`、`npm run check:art`、`npm run check:content`。
- 后端：`npm --prefix server run test`、`test:e2e`、`typecheck`、`build`；如未改后端，仅记录复验结果。
- GUI：优先启动本地 server/admin 后用浏览器检查页面；若登录态或环境阻塞，则在成果说明写明原因和人工截图点位。

## 5. 非目标
- 不新增数据库字段，不回退本地 JSON，不覆盖 `R000005`，不改历史发布快照，不实现动画系统、场景编辑器、CDN 或任务25能力。
