# 任务22远程MySQL迁移测试与后台端口5602调整计划

## 1. 目标

- 使用 `server/.env` 中的远程 MySQL 配置完成任务22迁移、Seed、Art 同步与发布链路验证。
- 将管理端本地开发端口从 `5666` 调整为 `5602`，避免与本机其他 Vben 项目冲突。

## 2. 范围

- 修改 `admin/apps/web-antd/package.json` 与 `admin/apps/web-antd/vite.config.ts`。
- 同步 `server/.env.example`、后端默认 CORS、后台使用文档中的端口说明。
- 不输出、提交或记录真实数据库密码。
- 不执行 `migrate reset`、`db push --force-reset`、`DROP DATABASE`。

## 3. 数据库步骤

- 先运行 `content:db:generate` 与 `content:db:status`。
- 通过临时脚本读取 `SELECT VERSION()`、`SELECT DATABASE()`、字符集和排序规则。
- 仅当数据库为 `cat_robot` 时执行 `content:db:migrate`。
- 执行 `content:db:seed` 与 `content:art:sync`。
- 运行数据库内容计数检查，确认敌人、背景、主角、关卡和美术资源落库。

## 4. 发布链路测试

- 使用 Nest 应用上下文调用 `ContentValidationService` 和 `ReleasesService`。
- 验证发布成功生成 `content_release`、`content_release_snapshot`、`content-store/published/content.snapshot.json` 与 `src/content/generated/contentSnapshot.ts`。
- 再运行 `check:content` 和根项目构建，确认游戏端可读取发布快照。

## 5. 管理端验证

- 端口改为 `5602` 后运行 `pnpm.cmd --dir admin typecheck`、`build`、`test`。
- 后端 CORS 默认值同步为 `http://127.0.0.1:5602`。
- 文档中的后台访问地址同步更新。

- 追加 `开发日记.md`。
