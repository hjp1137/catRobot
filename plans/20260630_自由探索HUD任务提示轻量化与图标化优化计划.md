# 自由探索 HUD 任务提示轻量化与图标化优化计划

## 1. 本任务目标
在不改变已有自由探索目标引导、资源定位、停刷提示、训练完成反馈等功能逻辑的前提下，对自由探索顶部 HUD 和任务提示区进行轻量化、图标化、按钮化优化。明显压缩 HUD 占用高度，将更多屏幕可视空间归还给游戏地图，提升玩家的移动与探索体验。

## 2. 当前真实 GUI 暴露的问题
当前自由探索顶部 HUD 将“训练场关卡名”、“自由探索状态”、“玩家血条”、“存活敌人”、“金币”、“目标：击败 8/12｜资源 0/3｜宝箱 1/1”以及“下一步：清理敌人”这 7 项信息集中在一个较高的半透明 HUD 大面板中（高安全区 + 94 像素）。在竖屏小游戏环境下：
- 挤压并遮挡了游戏地图，压缩了可视探索区域。
- 文字行数偏多，视觉上略显臃肿。

## 3. HUD 压缩方案
- **HUD 高度压缩**：
  将原来 `isExploreHud ? safeTop + 94 : safeTop + 54` 压缩为 `isExploreHud ? safeTop + 68 : safeTop + 54`。
  减少了 26 像素的高度，释放大量地图可视空间。
- **信息精简与布局调整**：
  - **第一行 (Y = safeTop + 6)**：
    - 左侧显示关卡名：`训练场`
    - 右侧显示存活敌人：`存活 9`
  - **第二行 (Y = safeTop + 24)**：
    - 左侧显示血条 (高度 12px)
    - 右侧显示金币数：`金币 +14`
    - 去除冗余的“自由探索”状态文字，腾出空间。
  - **第三行 (Y = safeTop + 42)**：
    - 展示轻量化的目标胶囊与下一步导航胶囊（高 20px，底边至 safeTop + 62，预留 6px 底边边距，面板高 68px）。

## 4. 目标图标化 / 胶囊化方案
在第三行依次渲染 3 个目标进度小胶囊：
- **敌 (击败敌人)**：当未完成时显示 `敌 8/12`（白色文字），完成时显示 `敌√`（绿色文字，背景微亮绿，绿色细边框）。
- **资 (收集资源)**：当未完成时显示 `资 0/3`（白色文字），完成时显示 `资√`（绿色文字，背景微亮绿，绿色细边框）。
- **箱 (开启宝箱)**：当未完成时显示 `箱 1/1`（白色文字），完成时显示 `箱√`（绿色文字，背景微亮绿，绿色细边框）。
- 胶囊使用圆角矩形（`fillRoundRect` 与 `strokeRoundRect`），单胶囊宽 68px，高 20px，间距 6px。

## 5. 下一步导航按钮方案
在第三行右侧富余区域（x = 238 起，宽度为 w - 16 - 238）渲染一个小型下一步导航胶囊：
- 击败未完成：显示 `[清敌 →]`（青色）
- 击败完成、资源未完成：显示 `[找资源 →]`（青色）
- 资源完成、宝箱未完成：显示 `[开宝箱 →]`（青色）
- 全部完成：显示 `[完成]`（绿色）
- 导航胶囊采用高亮描边风格，引导效果醒目。

## 6. 测试计划
- **修改测试用例**：
  由于更新了 HUD 渲染字符串，原测试中匹配 `目标：击败...` 和 `下一步：...` 的断言会失败。允许并需要同步更新：
  - `test/exploreTask14.test.ts`
  - `test/exploreTask15.test.ts`
  - `test/exploreTask16.test.ts`
  - `test/exploreTask16_1.test.ts` (新增，专项覆盖 HUD 紧凑相关布局及探针)
  使其适配最新的紧凑格式（例如匹配 `敌 \d+`、`资 \d+` 以及 `找资源` 等）。
- **单元测试执行**：
  运行 `npm run build` & `npm test`，确保全部自动化单元测试和构建测试顺利通过。
- **探针验证**：
  扩展 `getExploreTestState` 与 `ExploreTestState` 接口，暴露 `hudMode = 'compact'`、`hudHeight = 68`（不包含 safeTop 的 HUD 面板高）及 `objectiveCompactText` 字段。

## 7. 风险点
- **系统安全防线**：微信小游戏在不同平台对 Emoji 的支持有差异。推荐使用中文字符缩写 `敌`、`资`、`箱`，保证最大化跨平台兼容。
- **边缘方向箭头计算**：由于 HUD 高度变更为 68，边缘箭头的避让上边界值（`minY`）必须自动采用新的 HUD 底部高度（`safeTop + 68 + 10`）。
- **固定屏 1-1 隔离性**：固定屏战斗场景下 `isExploreHud` 为 false，高度和界面需继续保持 54 像素的原样。
