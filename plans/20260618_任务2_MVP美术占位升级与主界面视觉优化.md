# 任务2：喵喵机甲 MVP 美术占位升级与主界面视觉优化 方案

## 一、任务定位

视觉升级，不改玩法、不破坏 40 个现有测试。Canvas 2D 程序化绘制，不依赖外部图片。

## 二、模块化设计（新增 src/render/）

```
src/render/
├─ Theme.ts              # 颜色/字体/圆角等视觉常量（一处定义多处复用）
├─ DrawUtils.ts          # roundRect/渐变/描边/文本/血条/星形等原子绘制
├─ MechaRenderer.ts      # 橘猫重甲绘制（猫头+机甲身体+驾驶舱+能量核心）
├─ EnemyRenderer.ts      # 机械鼠绘制（金属身+尖鼻+红眼+天线）
├─ BackgroundRenderer.ts # 训练场背景（渐变+网格+暗角+能量环装饰）
└─ Effects.ts            # 受击闪烁/呼吸浮动/攻击闪光（基于 time，不依赖真实墙钟）
```

设计原则：
- render 层只依赖 `ICanvas2D`（来自 engine），不依赖 wx/DOM
- 所有方法接收 ctx + 参数，纯函数式，易测
- 颜色/尺寸常量集中 Theme，未来换皮只改一处

## 三、ICanvas2D 接口扩展

任务要求渐变背景，现有 ICanvas2D 无 `createLinearGradient/createRadialGradient`。
需扩展接口 + MockCanvas2D + FakeCanvas2D（test/wxRuntimeMock）+ WxGameContext 透传。
渐进色 API：`createLinearGradient(x0,y0,x1,y1): IGradient`，IGradient.addColorStop。
Mock 实现返回一个记录 stops 的假对象，fillStyle 接受它不报错。

## 四、受击/呼吸动效不破坏测试

- Effects 用传入的 `time`（秒）参数驱动正弦，不用 Date.now
- 调用方（PlayerMecha/BattleManager）传入 `ctx.now()` 或帧累积时间
- 受击闪烁：PlayerMecha 增加 `hitFlash` 计时器（takeDamage 时设 0.15s，update 递减）
- MockContext.now() 返回可控 clock，测试稳定
