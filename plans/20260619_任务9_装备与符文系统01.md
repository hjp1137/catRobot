# 任务9：装备与符文系统 0.1 方案

## 一、定位
新增装备掉落/背包/穿戴/属性加成 + 符文 0.1。不破坏任务1~8 的 232 测试。

## 二、EquipmentConfig（src/data/EquipmentConfig.ts）
- EquipmentSlot = 'weapon'|'armor'|'core'
- EquipmentRarity = 'common'|'rare'|'epic'
- EquipmentStats { hp?, attack?, skillDamageBonus?(0~1), damageReduction?(0~1), poisonResist?(0~1), cooldownReduction?(0~1) }
- EquipmentBaseConfig { id, name, slot, rarity, description, baseStats, power }
- 9 件装备（按文档表）
- RARITY_COLOR 映射（common灰/rare蓝/epic紫）
- EQUIPMENT_CONFIGS 注册表 + getEquipmentConfig

## 三、EquipmentData（src/data/EquipmentData.ts）
- EquipmentInstance { uid, configId, level, obtainedAt }
- EquipmentInventory { items: EquipmentInstance[], equipped: Partial<Record<slot,uid>> }
- createDefaultInventory()

## 四、RuneConfig + RuneData（src/data/RuneConfig.ts）
- RuneEffect { skillId?, skillDamageBonus?, shieldDurationBonus?, poisonResist? }
- RuneConfig { id, name, rarity, description, effect, power }
- 3 符文：cannon_rune_1（炮击+5%）/shield_rune_1（护盾+0.5s）/poison_guard_rune（毒液-15%）
- RuneInstance { uid, configId, obtainedAt }
- RUNE_CONFIGS + getRuneConfig
- 规则：最多装备2个；同 configId 允许重复（叠加效果），成果说明记录

## 五、PlayerData 扩展 + 迁移
```ts
equipmentInventory: EquipmentInventory
runeInventory: RuneInstance[]
equippedRunes: string[]  // uid 列表，最多2
```
SaveManager.migrate：补默认；穿戴 uid 不存在自动清理；equippedRunes 超2截断；configId 不存在防御。

## 六、EquipmentCalc（src/data/EquipmentCalc.ts）
纯逻辑：
- getEquippedItems(player) → EquipmentInstance[]
- getEquipmentStats(player) → EquipmentStats（累加穿戴装备）
- getRuneStats(player) → 累加符文 effect
- equipItem(player, uid) / unequipSlot(player, slot)
- equipRune(player, uid) / unequipRune(player, uid)（最多2）
- calculatePlayerBattleStats(player) → PlayerBattleStats（机甲基础 + 装备 + 符文，含上限保护：cooldownReduction≤0.5, damageReduction≤0.7, poisonResist≤0.8）
- getEquipmentPower(player) + getRunePower(player)

## 七、LootConfig + LootManager（src/data/Loot.ts）
- StageLootConfig { stageId, equipmentDropRate, rarityWeights, possibleEquipmentIds, runeDropRate?, possibleRuneIds? }
- 各关掉落配置（Boss 关高概率）
- rollLoot(stageId, random) → { equipment?: configId, rune?: configId } | null
- generateUid()

## 八、PowerCalc 扩展
calculateEquipmentPower(player) + calculateRunePower(player)；totalPower = base + skill + equipment + rune。

## 九、战斗接入
- PlayerMecha 构造接收 PlayerBattleStats（或 player），maxHp/attack 用装备加成后值
- SkillState cooldown 乘 (1-cooldownReduction)
- 喵能炮伤害乘 (1+skillDamageBonus)
- takeDamage 乘 (1-damageReduction)
- poison tick 乘 (1-poisonResist)
- 护盾 duration +shieldDurationBonus
- GameManager.mechaStats / battleStats getter 用 calculatePlayerBattleStats

## 十、UI
- EquipmentPanelUI（equipmentPanel 场景）：槽位+背包+符文槽+符文列表+穿戴/卸下
- MainUI 加「装备」按钮
- ResultUI 显示掉落装备/符文
- GameManager：equipmentPanel 场景 + goToEquipmentPanel；finishBattle 接入掉落（rollLoot + 写入 inventory + 存档）
