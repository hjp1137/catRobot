# 任务12.1：微信开发者工具 GUI 冒烟验证与战斗表现补调计划

1. 目标：补验任务12战斗界面真实运行风险；如本机无法打开微信开发者工具，则以 Node 微信运行时模拟器、构建和自动化测试兜底，并如实记录未验证项。
2. 检查页面：主界面、章节选择、关卡介绍、1-1 战斗界面、局内 HUD、右下技能按钮、战斗反馈对象。
3. 调整内容：仅微调 HUD 安全区、技能按钮热区/可读性、敌人初始分布、弹道/伤害数字/爆炸/掉落物表现参数和对象回收上限。
4. 验证方式：先写自动化断言覆盖安全区、技能按钮触控和反馈数量边界，再运行指定 typecheck/build/单测/npm test，并尝试定位或启动微信开发者工具。
5. 风险点：本机可能无微信开发者工具 GUI；Node 模拟器无法替代真实像素、触控物理尺寸、胶囊按钮遮挡和真机性能。
