# 计划：任务18发布包清理、音频闭环与单机版MVP封板 (CATROBOT-18-007)

本计划针对 CATROBOT-18-004 任务要求进行第四次迭代，主要内容为音频集成断言补全、WAV格式物理校验、资产清单修正、发布清单与包体统计口径统一，并完成 MVP 最终封板。

## 目标

1. **音频集成断言与 Mock**：
   - 补全生产链路的音频播放行为测试，设计 `test/soundIntegration.test.ts` 进行完整集成断言：
     - `pollButtonTap`：命中有效按钮播放 1 次 click，禁用或未命中时不播放。
     - 普攻与技能：普通击中和技能成功释放播放 attack；释放失败不播放。
     - Boss 波：1-5, 2-5, 3-5 Boss波生成时播放 alert；普通波不播放。
     - 胜利与失败：胜利播放 victory，失败播放 defeat，且在播放前先停止循环 alert。
     - 旧音频残留：战胜/战败结算重试或下一场战斗开始时，通过调用 `SoundManager.getInstance().stopAll()` 确保没有任何旧音频残留。
2. **WAV 物理格式校验**：
   - 在 `test/sound.test.ts` 中增加 WAV 文件的物理头解析断言，验证 `click.wav`, `attack.wav`, `alert.wav`, `victory.wav`, `defeat.wav`：
     - 文件头必须是 `RIFF` / `WAVE` 格式。
     - 格式编码必须是 PCM 编码。
     - 通道数必须是单声道 (Mono, 1)。
     - 采样率必须是 11025Hz。
     - 位深必须是 16-bit。
     - 校验这五个文件的实际字节数与资源清单 `ASSET_MANIFEST.md` 声明的字节数一致。
3. **资产清单与描述修正**：
   - 修正 `assets/ASSET_MANIFEST.md`：
     - 将五个 WAV 文件的规格从 8-bit 改为 16-bit。
     - 移除 MIT 许可声明，仅声称为 “本地原创”，不列公开商用授权为 MVP 阻断项。
   - 修正所有 “1-1 关卡” 的描述，从 “Boss房” 修正为 “普通战斗与新手引导”。Boss 仅在 1-5, 2-5, 3-5 出现。
4. **统计口径统一与包体校验**：
   - 以 `npm test` 中发布校验输出的文件数和字节数为唯一正式指标，并在 `Walkthroughes/`、`ANTIGRAVITY_RESULT.md` 以及 `开发日记.md` 中完全对齐：
     - 文件数：127
     - 包大小：1,214,471 字节
     - 包含 62 个 JS、48 张 PNG、5 个 WAV 以及 12 个其它辅助/配置文件。
     - 取消项目目录物理体积统计以防漂移。
5. **发布排除与封板**：
   - 确认异常文件 `{` 不复发。
    - 包发布校验结果通过后，设置状态为 `CATROBOT-18-007 / BLOCKED`，阻断原因为等待用户真机/微信开发者工具补验。
