# 任务24 美术资源上传版本替换 Manifest 自动登记与发布管理计划

## 1. 当前现状
- 任务17已建立基础 `ArtManifest.ts`、Resolver 和 `check:art`。
- 任务21至23已建立内容模板、后台、NestJS、Prisma、远程 MySQL 和内容发布快照。
- 当前 `content_art_resource` 只保存资源索引，后台仅只读列表，图片仍依赖手工放置与手工 Manifest。

## 2. 资源版本模型
- 保留 `content_art_resource` 作为 Art Key 主数据。
- 新增 `content_art_resource_version` 记录每次上传的不可变版本。
- 在主表补充尺寸策略、透明规则、草稿版本、发布版本、启停和软删除字段。
- 已发布版本只读，草稿版本允许选择和安全删除。

## 3. 文件存储方案
- 原图写入 `content-store/art/uploads/{safeArtKey}/{versionId}/original.ext`。
- 缩略图写入 `content-store/art/thumbnails/{versionId}.webp`。
- 发布资源写入 `assets/art-releases/{releaseVersion}/...`。
- API 不接受物理路径，所有路径由服务端标准化生成。

## 4. 上传安全方案
- 使用 multipart 接收文件，限制大小和数量。
- 服务端检查真实文件签名、MIME、扩展、像素总数和 Sharp 解码结果。
- 禁止 SVG、GIF、BMP、TIFF、PSD、ICO、压缩包和未知二进制。
- 上传失败清理临时文件，不修改当前草稿版本。

## 5. 图片校验方案
- PNG 检查文件头和透明通道；JPEG 仅允许背景、地图类资源。
- `exact` 要求实际宽高完全一致。
- `recommended` 尺寸不一致产生警告。
- `free` 只执行安全尺寸和解码检查。

## 6. 缩略图方案
- 使用 Sharp 生成 256px 以内 WebP 缩略图。
- 缩略图仅供后台预览，不进入小游戏发布包。

## 7. 数据库迁移方案
- 新增 Prisma enum 和模型，生成向前迁移 SQL。
- 迁移不删除旧资源，不覆盖 Art Key，不执行 reset、truncate 或 drop。
- 已有 physical 资源通过同步脚本初始化为 v1；virtual/fallback 允许无物理版本。

## 8. Art Manifest 生成方案
- 新增发布 Art Manifest Snapshot JSON 与 TS。
- 游戏 Resolver 读取顺序为发布快照、基础 Manifest、fallback。
- 基础 `ArtManifest.ts` 继续作为内置兼容层，后台不直接改写它。

## 9. 发布资源包方案
- 发布时只打包启用内容引用到的 Art Key 与必要 fallback。
- 先写 staging，再写版本化目录，失败不覆盖上一版资源。
- Manifest 只记录项目相对路径、版本、尺寸、透明通道和 checksum。

## 10. 内容发布联动方案
- 内容快照追加 Art Manifest release id、checksum 和资源版本列表。
- 发布成功后回填主表 `published_version_id` 并标记版本为 published。

## 11. 历史恢复方案
- 恢复历史发布时只恢复为草稿选择，不直接修改旧发布版本。
- 用户重新校验并发布后，新发布版本才进入游戏。

## 12. 后台页面方案
- `/content/resources` 升级为资源列表、筛选、新建 Art Key、上传、详情、版本历史和对比。
- `ArtResourceSelector` 显示缩略图、草稿/发布状态、尺寸、资源类型和上传入口。
- 敌人、背景、主角页面继续复用公共选择器。

## 13. 测试计划
- 先写后端服务单测覆盖创建 Art Key、上传校验、重复 checksum、草稿选择和删除保护。
- 补游戏端测试覆盖 Art Manifest Snapshot 优先与 fallback。
- 补脚本测试或命令验证 `check:art` 检查发布快照。
- 运行根项目、后端、Prisma 和管理端现有验证命令。

## 14. 正式库安全措施
- 禁止 `migrate reset`、`db push --force-reset`、DROP、TRUNCATE 和无条件 DELETE。
- 正式库只执行已审查 migration deploy 和可恢复的最小验证。
- 文档、日志和快照不写入真实数据库密码。

## 15. 不处理范围
- 不做裁剪、AI 生图、PSD/SVG/GIF/视频/音频、序列帧编辑器、骨骼动画、CDN、对象存储、在线热更新或战斗平衡修改。
