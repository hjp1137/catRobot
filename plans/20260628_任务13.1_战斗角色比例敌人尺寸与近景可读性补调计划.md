# 任务13.1：战斗角色比例、敌人尺寸与近景可读性补调计划

## 本任务目标
- 在固定屏战斗内补调玩家、敌人、弹道、血条、伤害数字与波次提示的近景可读性。
- 保留任务13自动攻击、三波次、护盾、喵能炮、胜负判定机制。
- 保留任务12.2背景暗幕、玩家光环、普通敌人灰底规避成果。

## 当前截图暴露的问题
- 普通敌人尺寸偏大，程序化圆形特征偏临时。
- 敌人靠近玩家后站位拥挤，近景元素容易互相遮挡。
- 玩家血条、弹道、伤害数字、波次提示需要避开高密度战斗区域。

## 参数调整方向
- 集中新增或复用显示配置：玩家显示缩放、普通敌人显示缩放、精英敌人显示缩放。
- 提升敌人分离半径、敌人停留距离、顶部 HUD 和底部技能区边界约束。
- 上移玩家血条，控制玩家光环透明度，微调弹道宽度、伤害数字字号和波次提示时长。

## 测试计划
- 先补显示缩放、敌人分离、HUD/技能区边界、灰底规避、波次 HUD 不回退等断言。
- 再执行 `npm run typecheck`、`npm run build`、任务指定单测和 `npm test`。

## 风险点
- 只改显示与轻量站位，不改碰撞盒、伤害数值和任务13主流程。
- 程序化敌人细节要控制绘制成本，避免性能和对象池回退。
- GUI 自动化不纳入本轮，成果说明只提供手动微信开发者工具验证步骤。
