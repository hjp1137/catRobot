# 任务12.2 资产证据成果命名与透明像素校验修正计划

## 1. 目标与背景
在任务12.1中，美术素材已经规格化并实现了透明通道和压缩，且已通过现有测试。但还存在以下证据与校验漏洞需要修复：
1. 10张素材实际总大小为 748,213字节，但 ASSET_MANIFEST.md 与 ANTIGRAVITY_RESULT.md 写为 738,213字节。
2. 成果文件 `20260620_任务12.1_美术素材规格与真实校验测试成果说明.md` 缺少项目名“喵喵机甲”，需要更名为 `Walkthroughes/20260620_任务12.1_喵喵机甲_美术素材规格与真实校验测试成果说明.md` 并补充缺少的章节。
3. `test/assets.test.ts` 尚未自动断言角色和图标至少存在一个真实透明像素。
4. 测试中的总字节数需要与磁盘实时统计一致并进行断言。

## 2. 详细执行步骤

### 2.1 修正资产清单 ASSET_MANIFEST.md 与 ANTIGRAVITY_RESULT.md
- 更新 `assets/ASSET_MANIFEST.md` 中的“实际总大小”以及各项体积说明，确保数值准确为磁盘实际大小 748,213 字节。
- 修正 `ANTIGRAVITY_RESULT.md` 中的文件总体积，并同步更新测试通过数量（由于我们会在 `test/assets.test.ts` 中增加针对 9 张素材的透明像素内容校验测试）。

### 2.2 成果文件更名与内容补齐
- 将成果说明更名为 `Walkthroughes/20260620_任务12.1_喵喵机甲_美术素材规格与真实校验测试成果说明.md`。
- 按项目统一成果模板补齐所有缺失的章节（任务目标、完成内容、新增或修改文件、运行方式、自动化测试结果、微信开发者工具验证结果、发现的问题、修复的问题、未完成事项、已知问题、下一步建议、验收点覆盖表）。
- 明确素材为“内部原型可替换素材”，不表述为正式商用授权。

### 2.3 增强真实资产测试
- 在 `test/assets.test.ts` 中引入自研轻量 PNG 像素解析算法，对于除背景外的 9 张素材，解析其 IDAT 块并解压还原像素的 Alpha 通道，断言其中至少存在一个透明像素（Alpha < 255）。
- 在测试中实时统计并断言 10 张图片的总字节数为 748,213 字节。

### 2.4 测试与验证
- 运行 `npm run typecheck` 确认类型安全。
- 运行 `npm run build` 确保能够成功构建。
- 运行 `npm test` 确认所有测试全部通过。
- 将 `ANTIGRAVITY_TASK.md` 状态变更为 `AWAITING_REVIEW`。
- 物理更新 `开发日记.md`。
