# 任务32：自由探索平面地图、碰撞与动作视觉修复计划

## 目标

修复训练场中敌人过小/不清晰、主角移动时回退红白旧图、整张纵向插画被误作地图，以及可穿透障碍物的问题。保持 Art Key、内容快照和历史 Release 不变；在现有 ExploreScene、渲染器和输入链路内增量实现。

## 约束

- 地图改为可读的 2D 平面战术区：地板、障碍、通道、边界和可走区域使用同一世界坐标。
- 只按已发布 Art Manifest 解析资源；不得把旧红色资源当移动帧回退。
- 碰撞在移动计算时处理，敌人和主角均不得穿越阻挡区；不新增平行地图/发布体系。
- 先写红测试：资源状态优先级、角色/敌人画面尺寸、障碍阻挡与可绕行路径。

## 验收

1. 训练场不再铺满纵向插画，玩家可辨识地在平面地板/障碍/通道上移动。
2. 角色移动只用 `player.mechaCat.move`（不可用时回退当前主角 idle），不切回旧红色资源；敌人视觉尺寸清晰且显著大于当前截图表现。
3. 直线撞障碍被截停，沿通道可继续移动；既有训练场、正式自由地图和固定屏回归通过。
4. 完成 `typecheck`、`build`、`check:art`、相关测试和全量 `npm test`，并更新成果说明/开发日记。
