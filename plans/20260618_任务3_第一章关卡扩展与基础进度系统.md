# 任务3：第一章关卡扩展与基础进度系统 方案

## 一、任务定位
从单关卡 Demo 扩展为第一章可推进的闯关原型：多关卡配置 + 关卡选择界面 + 解锁/通关记录 + 星级 + 区分首通/重复奖励。不改玩法核心、不破坏旧 53 测试与旧存档。

## 二、数据模型重构

### StageConfig（重写）
```ts
interface StageEnemyConfig { enemyId: string; count: number; }
interface StageConfig {
  id, chapterId, name, subtitle?, recommendedPower,
  enemies: StageEnemyConfig[],
  rewardGold, rewardParts,
  unlockAfter?: string,   // 通关哪个关卡后解锁
  spawnMargin?: number,
}
```
工具函数：getStageById / getAllStages / getChapterStages / getFirstStage / getNextStageId / isFirstClear 后判断

### ChapterConfig（新增 src/chapter/）
```ts
interface ChapterConfig { id, name, subtitle?, stageIds: string[] }
```
第一章：废弃训练场，5 关 1-1..1-5。

### EnemyConfig（扩展 id + variant）
```ts
interface EnemyConfig {
  id, name, maxHp, attack, speed, attackInterval, radius,
  color?, variant?: 'normal'|'elite'
}
```
新增 `elite_mouse`（强化机械鼠 80hp/5atk/1.8s）。旧 `mouse` 字段名 hp→maxHp（兼容映射）。

### PlayerData（扩展进度）
```ts
interface StageProgress { cleared, bestStars, clearCount, firstClearedAt?, lastClearedAt? }
interface PlayerData {
  version, mechaId, level, gold, parts,
  stageProgress: Record<string, StageProgress>,
  unlockedStageIds: string[],
  selectedStageId?: string,
}
```
SaveManager.migrate 补：旧存档无 stageProgress → 默认 {}，无 unlockedStageIds → 默认 ['1-1']。

## 三、ProgressManager（新增 src/chapter/）
封装进度逻辑（纯函数，易测）：
- `isUnlocked(player, stageId)`：在 unlockedStageIds 或 isFirstStage
- `canChallenge(player, stage)`：解锁即可挑战（低战力只提示不禁止）
- `computeStars(hpRatio, elapsedSec)`：基础1 + hp≥50% +1 + elapsed≤60 +1，上限3
- `applyClear(player, stage, stars, elapsed)`：更新 cleared/bestStars(max)/clearCount/解锁下一关，返回奖励 {gold, parts, firstClear}
- `getReward(stage, isFirstClear)`：首通100% / 重复50%(向下取整)
- `getNextStageId(stageId)`：按章节顺序

## 四、BattleManager 配置驱动
- start(stage) 按 `stage.enemies[]` 循环生成不同 enemyId 的敌人
- 记录 battleStartTime / battleEndTime，结算时算 elapsed
- endBattle 调 `game.finishBattle(outcome)`，outcome 带 stageId + elapsed，GameManager 委托 ProgressManager.applyClear

## 五、GameManager 场景机扩展
- scene 类型加 `'stageSelect'`：menu → stageSelect → battle → result → stageSelect（返回关卡选择）
- `startBattle(stageId)`：校验解锁，设 selectedStageId，进 battle
- `finishBattle(outcome)`：胜利时 ProgressManager 发奖+解锁+存档，emit 数据变更
- 返回逻辑：result → stageSelect（不再直接回 menu）

## 六、UI
- MainUI：「开始战斗」→「进入第一章」(id 仍可点)，点击 → scene=stageSelect
