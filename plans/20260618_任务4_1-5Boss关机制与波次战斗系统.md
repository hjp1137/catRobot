# 任务4：1-5 Boss 关机制与波次战斗系统 方案

## 一、定位
把 1-5 升级为 Boss 关 + 引入波次系统 + Boss 技能 + 关卡介绍 + 章节完成反馈。不破坏任务1~3 的 88 测试与旧存档。

## 二、数据层扩展

### StageConfig（加 waves + isBossStage）
```ts
interface StageWaveConfig { id, name?, enemies: StageEnemyConfig[], spawnDelay?, message? }
interface StageConfig {
  ...现有,
  waves?: StageWaveConfig[],
  isBossStage?: boolean,
}
```
兼容：无 waves 时把 enemies[] 视为单波（BattleManager/WaveManager 统一处理）。

### EnemyConfig（加 boss variant）
```ts
type EnemyVariant = 'normal' | 'elite' | 'boss'
```
新增 `mecha_rat_king`：220hp/7atk/1.6s/radius32/boss。
（任务文档建议的 enemyId 改名 mechanical_mouse/reinforced_mouse，但旧测试与配置用 mouse/elite_mouse，保留旧 id 兼容，仅新增 king。文档数值采用其建议但 id 沿用现有命名约定。）

## 三、WaveManager（新增 src/battle/）
- start(stage)：把 stage.waves（或 [singleWaveFromEnemies]）存为队列，spawn 第一波
- update(dt, spawnFn)：当前波敌人全死 → 触发 waveChangeEvent + spawnDelay 后 spawn 下一波
- 暴露：currentWaveIndex / totalWaves / currentMessage / isLastWaveCleared / pendingNextDelay
- 波次切换提示由 BattleUI 读取 currentMessage 显示

## 四、BossSkill（新增 src/battle/BossSkill.ts）
震荡冲击（Shockwave）：
- 状态机：idle → warning(1s 红圈预警) → blast(瞬间判定+扩散环) → cooldown(5s)
- 字段：cooldownTimer / phase / phaseTimer / center(x,y) / radius / damage / hasHitThisBlast
- update(dt, boss, player)：推进状态；warning 期满进入 blast，blast 时若玩家在 center 半径内且未命中过 → player.takeDamage
- 召唤小鼠（可选 B）：boss hp<50% 且未触发过 → spawn 2 mouse，每场最多 1 次。由 BattleManager 通过回调注入 spawn
- boss dead → reset/stop

预警圈/扩散环绘制：render 层 drawShockwave（在 Effects 或 BossRenderer）

## 五、EnemyMouse 扩展
- variant 支持 'boss'
- boss 持有 BossSkill 实例（仅 boss variant 创建）
- update(dt, player) 时：若 boss，推进 bossSkill；接触伤害逻辑保留
- 暴露：isBoss / bossSkill / 触发召唤回调

## 六、BattleManager 改造
- start(stage)：创建 WaveManager，start；不再一次性 spawn 全部
- update(dt)：WaveManager.update 推进波次（通过 spawn 回调生成敌人）；现有敌人 update；玩家 update；boss 的 BossSkill 判定
- 胜利条件改为「WaveManager 最后一波清空」
- 暴露：currentBoss（当前存活的 boss 敌人）/ waveMessage / waveIndex / totalWaves / isBossStage

## 七、render
- EnemyRenderer：boss variant 更大 + 王冠 + 背部能量核心 + 红光晕 + 红电子眼
- 新增 render/BossRenderer 或 Effects.drawShockwave：预警红圈（脉动）+ 扩散环
- BattleUI：Boss 血条（顶部 HUD 下方，红色长条 + Boss 名）

## 八、UI
- StageIntroUI（新）：关卡名/副标题/推荐战力/敌人信息/奖励/Boss提示/开始挑战/返回。scene 'stageIntro'
- GameManager：startBattle 改为先去 stageIntro；stageIntro 点开始才真进 battle
- ResultUI：首次通关 1-5 显示「第一章完成！」（由 outcome.clearResult.firstClear + stageId==='1-5' 判定）
- StageSelectUI：1-5 卡片红色边框 + Boss 图标

## 九、ProgressManager
- 不新增 chapterProgress；第一章完成由「1-5 cleared」推导
- ClearResult 加 chapterCompleted?: boolean（首次通关 1-5 时 true）

## 十、兼容

- 旧存档无新字段 → 已由任务3 migrate 覆盖（无新持久化字段，仅运行时）
- 旧测试 smallStage({enemies}) 仍可用（WaveManager 转 single wave）
