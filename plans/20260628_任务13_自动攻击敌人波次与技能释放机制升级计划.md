# 任务13：自动攻击、敌人波次与技能释放机制升级计划

## 目标
- 在不重构整体架构的前提下，让 `1-1` 具备自动锁敌普攻、真实飞行弹道、多波次刷怪、敌人推进、两个主动技能、波次 HUD 与胜负收口。
- 保留任务12系列的 HUD 安全区、技能热区、暗幕、玩家光环、反馈池上限、devtools 战斗测试入口和调试探针。

## 自动攻击设计
- 扩展战斗配置：范围、间隔、伤害、弹道速度、弹道寿命。
- 默认锁定最近存活敌人；目标死亡、越界或无效时重新选择。
- 普攻只生成飞行弹道，命中时再结算伤害并复用命中特效、伤害数字和爆点。

## 波次设计
- `StageConfig` 为 `1-1` 增加 3 波配置，支持出生延迟、敌人类型、数量、精英和出生组。
- `BattleManager` 维护当前波次、已生成、存活、下一波等待时间，清完最后一波后触发胜利。
- HUD 显示当前波次和当前存活/本波总数。

## 技能设计
- 护盾：点击后进入冷却，持续 4 秒，玩家周围显示护盾光圈，并减少受到伤害。
- 喵能炮：点击后锁定最近敌人中心范围，对最多 5 个敌人造成范围伤害，生成爆炸和伤害数字。
- 冷却期间禁止重复释放，按钮遮罩和数字与真实状态一致。

## 测试计划
- 先新增或扩展自动攻击、弹道命中、波次推进、技能冷却、护盾持续、范围技能、胜负判定和探针断言。
- 按任务要求运行 `npm run typecheck`、`npm run build`、指定单测和 `npm test`。

## 风险点
- 不能破坏任务12系列视觉补调和反馈池上限。
- 波次后胜利时间会影响数值基线，需要同步调整期望。
- GUI 自动化不作为本轮硬性要求，成果说明只提供手动验证步骤。
