# 任务6：技能养成与机甲成长扩展 方案

## 一、定位
把任务5局内技能扩展为持久化养成（等级1~5，消耗金币/零件升级，效果随等级成长），加技能养成界面 + 战力含技能贡献。不破坏任务1~5 的 135 测试与旧存档。

## 二、SkillConfig 重构（保留兼容）
任务5 SkillConfig 是单值（cooldown/damage/duration/damageReduction/range/halfAngle）。重构为等级成长：
```ts
interface SkillLevelEffect { level, damage?, cooldown?, duration?, damageReduction?, range?, halfAngle? }
interface SkillUpgradeCost { level, gold, parts }  // 升到该等级的消耗
interface SkillConfig { id, name, description, type, maxLevel, effects: SkillLevelEffect[], upgradeCosts: SkillUpgradeCost[] }
```
工具：
- `getSkillEffect(skillId, level)` → 取该等级 effect（钳制 1..maxLevel）
- `getSkillUpgradeCost(skillId, currentLevel)` → 升到 currentLevel+1 的消耗（满级返回 null）
- 保留 `DEFAULT_SKILL_IDS`

数据用任务文档建议的数值表（喵能炮5级/重甲护盾5级）。halfAngle 不变（45°）。

## 三、PlayerData 扩展 + 迁移
```ts
interface PlayerData {
  ...现有,
  unlockedSkillIds: string[],          // 默认 ['meow_cannon','heavy_shield']
  skillLevels: Record<string, number>, // 默认 { meow_cannon:1, heavy_shield:1 }
}
```
SaveManager.migrate：旧存档无字段补默认；skillLevels 缺某技能补1；<1 修正1；>maxLevel 修正 maxLevel。

## 四、SkillUpgrade（新增 src/data/SkillUpgrade.ts，纯逻辑）
```ts
getSkillLevel(player, skillId): number  // 钳制 1..maxLevel
getSkillEffectForPlayer(player, skillId): SkillLevelEffect
getSkillUpgradePreview(player, skillId): { current, next?, cost? }
tryUpgradeSkill(player, skillId): SkillUpgradeResult
```
SkillUpgradeResult: { ok, reason?, oldLevel, newLevel, costGold, costParts }
逻辑：未解锁/满级/资源不足 拒绝；足够则扣费+1级。

## 五、战力扩展（src/data/MechaConfig 或新 PowerCalc）
现有 `computePower(maxHp, attack)`。新增：
```ts
calculateSkillPower(player): number  // 喵能炮等级×20 + 重甲护盾等级×20
calculateTotalPower(player): number  // 基础 + 技能
```
GameManager.stats.power 改用 calculateTotalPower。推荐战力对比随之含技能。
注意：旧测试 save.test 断言 power 数值需同步（power 现含技能贡献，Lv1=120+10*10 + (1+1)*20 = 240）。

## 六、SkillState/PlayerMecha 接入等级
- SkillState 构造接收 `effects per level`（而非单值 cfg）：cooldown/activeRemaining 用当前等级 effect
- PlayerMecha 构造接收 skillLevels（或 PlayerData），按等级初始化 SkillState
- useSkill 喵能炮：damage/range/halfAngle 读当前等级 effect
- takeDamage 护盾减伤：读当前等级 damageReduction
- BattleManager.start 创建 PlayerMecha 时传 game.player.skillLevels

## 七、GameManager

- doUpgradeSkill(skillId)：委托 tryUpgradeSkill，成功存档+emit；返回结果给 UI
- stats.power 用 calculateTotalPower
