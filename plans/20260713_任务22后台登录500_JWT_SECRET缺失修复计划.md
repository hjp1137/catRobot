# 任务22后台登录500 JWT_SECRET缺失修复计划

## 1. 问题

- 登录请求已能提交到后端，但浏览器 Network 显示 `/auth/login` 返回 500。
- 后端健康检查正常，问题发生在登录流程内部。

## 2. 诊断结论

- `server/.env` 中 `JWT_SECRET` 为空。
- AuthService 在账号密码校验通过后调用 `jwt.signAsync`，缺少 secret 会抛运行时异常。
- 该异常被 Nest 返回为 500。

## 3. 修复方案

- 在 `server/.env` 中生成本机随机 `JWT_SECRET`，不输出密钥内容。
- 在 `DATABASE_URL` 中增加 Prisma 连接池限制，避免远程 MySQL 连接数耗尽。
- 重启后端服务，使新环境变量生效。
- 用临时管理员账号验证登录链路可签发 token。

## 4. 验证

- `/api/health` 正常。
- `/api/health/database` 正常。
- `/api/auth/login` 使用临时账号返回 accessToken。
- 删除临时账号，不保留测试数据。
