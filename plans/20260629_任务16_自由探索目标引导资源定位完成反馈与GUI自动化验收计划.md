# 任务16 自由探索目标引导、资源定位、完成反馈与微信开发者工具 GUI 自动化验收计划

本任务目标是在自由探索模式中加入轻量级目标引导、边缘方向箭头、屏内目标高亮、HUD 下一步提示、击败完成停刷提示以及训练完成反馈，并通过自动化测试和微信开发者工具 GUI 自动化进行验证。

## 当前问题分析
1. **剩余资源定位难**：地图大，未收集资源散落在各处，玩家在击败怪后无所适从。
2. **状态停刷和完成无感**：击败达到 12/12 后敌人停刷了，但没有任何提示；最终所有目标完成后直接变成“训练完成”，但缺乏界面高光仪式感。
3. **缺少边缘与屏内引导**：玩家无法在屏幕边缘得知未完成目标的方向，近处也没有高亮呼吸圈等标识。

---

## 引导系统设计

### 1. 引导目标选择逻辑
新增 `src/explore/ExploreGuideSystem.ts`。每帧更新计算当前的被引导目标：
- 优先级：
  1. 若击败未完成 (`enemyKillGoalCompleted === false`)：引导最近的活着的敌人；如果当前无活着敌人，引导距离玩家最近的活跃 `spawnPoint`。
  2. 若击败已完成，但资源未完成 (`resourceGoalCompleted === false`)：引导最近的未收集资源点 (`node.collected === false`)。
  3. 若资源已完成，但宝箱未完成 (`chestGoalCompleted === false`)：引导最近的未开启宝箱 (`chest.opened === false`)。
  4. 若三项目标全部完成：当前引导类型为 `'complete'`。
- 坐标转换：
  - 计算玩家与目标的欧氏距离 `distance` 和世界坐标。
  - 判断是否在屏幕内：`worldToScreen(scene.camera, targetWorldPoint)` 所得的屏幕坐标在屏幕视口宽高范围内。

### 2. 屏幕边缘方向箭头与文本
- 仅在 `visibleOnScreen === false` 且引导类型不是 `'complete'` 时显示。
- 屏幕安全矩形（避开顶部 HUD、避开左下角摇杆 `(x < 120 && y > h - 120)`，避开右下角技能 `(x > w - 120 && y > h - 120)`）。
- 计算射线与安全矩形的交点为箭头位置，箭头方向指向目标，旁边显示文字如 `资源 320`。

### 3. 屏内目标高亮
- 在 `ExploreRenderer.ts` 渲染时，对于匹配当前引导目标 id 的实体：
  - **资源点**：绘制半径更大、粗细有呼吸动效的光圈，上方渲染文字 `目标资源`。
  - **宝箱**：金色呼吸外描边，上方渲染文字 `补给箱`。
  - **敌人**：在头部绘制一个倒三角形红色指针，并标注 `清理敌人`。

### 4. HUD 下一步提示与公告
- **HUD 下一步提示**：顶部 HUD 信息中新增 `下一步：[提示]`，提示文案如“清理敌人”、“寻找资源”、“打开宝箱”。
- **清剿完成停刷提示**：当 `enemyKillGoalCompleted` 从 false 变为 true 时触发，显示 `清剿完成，敌人刷新已停止` 或 `继续寻找资源`，持续 2.0s。
- **训练完成反馈**：当全部目标完成且刚完成时触发，在屏幕中央弹出带有背景和边框的“训练完成”面板，说明“本轮训练目标已完成”，持续 3.0s。
