# 任务22后台登录表单校验无响应修复计划

## 1. 问题

- 管理端登录页输入用户名和密码后点击登录，页面仍提示 `username is required` 与 `password is required`。
- 后端 `3100` 健康检查正常，问题优先定位在前端表单校验层。

## 2. 根因

- `LoginView.vue` 中 `a-form-item` 使用了 `name="username"` 与 `name="password"`。
- 外层 `a-form` 未绑定 `:model="form"`，Ant Design Vue 校验无法从表单模型读取输入值。
- 因校验失败，`@finish="submit"` 不触发，表现为登录按钮无反应。

## 3. 修复方案

- 在 `LoginView.vue` 的 `<a-form>` 增加 `:model="form"`。
- 新增前端测试，检查登录表单绑定了 `form` 模型，避免回归。

## 4. 验证

- 先运行管理端测试确认新增断言失败。
- 修复后运行 `pnpm.cmd --dir admin test`、`typecheck`、`build`。
- 验证后端 `/api/health` 正常，必要时提醒用户创建管理员账号。
