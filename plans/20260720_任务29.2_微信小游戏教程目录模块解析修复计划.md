# 任务29.2 微信小游戏教程目录模块解析修复计划

## 问题

- 微信开发者工具无法解析游戏端编译产物中的 `../../shared/tutorial-catalog/index.js`。
- 该路径跨出 `dist` 并依赖 Node 的目录入口解析，小游戏 CommonJS 运行时将其归一为缺失的 `shared/tutorial-catalog.js`。
- 控制台的 `await` 语法错误来自调试控制台历史输入，不是游戏源代码顶层 await。

## 最小修复

1. 先增加回归测试：游戏端教程代码必须引用编译进 `dist/tutorial` 的目录模块。
2. 在 `src/tutorial/TutorialCatalog.ts` 放入游戏运行时所需的功能与目标元数据，保留 `shared/tutorial-catalog` 供服务端和发布快照使用。
3. 游戏端三个引用全部改为同一 `src/tutorial` 模块，避免编译产物跨出 `dist`。
4. 编译后验证 `dist` 不再引用 `shared/tutorial-catalog`，并运行教程相关及全量根测试。

## 边界

- 不改引导流程、19 步数据、发布快照、管理端或远端数据库。
- 不清理开发者工具控制台历史；重新编译后由用户清空并刷新即可。
