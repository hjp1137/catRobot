# 符文成长、合成与图鉴实施计划

日期：2026-10-18。依据已批准的《符文等级词条与三合一属性规划》。

## 可观察成功标准

- 14 个常规家族具有 1～6 级、随机主副词条和 3 级起的机制；结果持久化，切页或读档不重抽。
- 三枚同级、未绑定、未锁定符文定向合成；主材料决定家族和已有机制分支，失败保存完整回滚。
- 图鉴展示各级外观、范围、机制与拥有数量；背包能查看、锁定、选择材料及合成。
- 数值与机制实际进入战斗；武器词条区分左右手，机制去重且受上限约束。
- 正式胜利按难度产出符文，首通定向和三星自选可领取；训练、失败不产出永久符文。
- 旧符文 UID、孔位、原始效果和作用域保留；非法新词条不能进入存档。

## 阶段与分工

1. 模型、迁移与经济：`rune_model_implementation` 独占 `pilot_state.gd`、`pilot_equipment.gd`、`content_db.gd`、`rune_socket_model.gd`、必要的 `pilot_legacy.gd`、`rune_catalog.json`，及新增符文模型脚本、模型测试。
2. 战斗与 UI 并行接入：`rune_combat_implementation` 负责战斗消费与机制；`rune_ui_implementation` 负责图鉴、背包、合成、锁定和奖励选择。主代理集成接口、审查、记录。
3. 集成审查与实机验收：相关模型/战斗/UI 回归、隔离存档迁移和失败保存检查，再检查实际图形与输入流程。
