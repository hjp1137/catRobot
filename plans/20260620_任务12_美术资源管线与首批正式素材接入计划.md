# 任务12：美术资源管线与首批正式素材接入计划

本计划旨在为《喵喵机甲：星核觉醒》建立统一的美术资源加载管线，并接入首批本地美术素材，提供程序化绘制兜底与屏幕适配。

## 1. 资源清单与存储设计
首批素材存放于 `assets/` 目录，统一为 PNG 格式，带有透明背景：
- `assets/main_bg.png` (主界面背景，800x1200)
- `assets/player_mecha.png` (橘猫机甲，128x128)
- `assets/enemy_rat.png` (基础机械鼠，64x64)
- `assets/coin.png` (金币，64x64)
- `assets/part.png` (零件，64x64)
- `assets/stone.png` (强化石，64x64)
- `assets/equip_icon.png` (装备图标，64x64)
- `assets/rune_icon.png` (符文图标，64x64)
- `assets/skill_cannon.png` (技能-喵能炮图标，64x64)
- `assets/skill_shield.png` (技能-重甲护盾图标，64x64)

## 2. 接口与运行时适配
- **IContext 与 ICanvas2D 扩展**：
  - `ICanvas2D` 增加 `drawImage` 接口以支持图片渲染。
  - `IContext` 增加 `createImage()` 接口用于跨环境实例化图片。
- **WxGameContext**：使用 `wx.createImage` 或浏览器 `new Image` 实例化。
- **MockContext**：提供模拟的 `MockImage`（可手动触发 onload/onerror），用于 Node 下单元测试。

## 3. ResourceManager 资源管理器
- 新建 `src/core/ResourceManager.ts`，管理图片资源的加载状态（PENDING/LOADING/LOADED/FAILED）。
- 提供 `loadAll(context: IContext): Promise<void>`，异常捕获防止白屏。
- 提供 `getImage(key: string): any`、`isLoaded(key: string)` 及 `isFailed(key: string)`。

## 4. 渲染层接入与兜底
- 主界面背景、机甲、机械鼠、奖励、图标等绘制逻辑：
  - 若 `ResourceManager` 返回可用图片，使用 `drawImage` 进行居中/自适应拉伸绘制。
  - 若图片加载未完成或失败，自动回退到原有程序化绘制。
- 坐标及触摸判定完全基于原有逻辑坐标，不受图片绘制影响。

## 5. 测试验证计划
- **单元测试** (`test/resource.test.ts`)：验证资源加载成功、失败回退、缓存及重复加载。
- **集成测试**：在 `test/smoke.runtime.test.ts` 中扩展模拟器，测试加载成功与失败流程的完整运行。
- 运行 `npm run typecheck`、`npm run build`、`npm test` 确保 100% 通过。
