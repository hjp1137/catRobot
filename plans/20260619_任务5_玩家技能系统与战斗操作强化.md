# 任务5：玩家技能系统与战斗操作强化 方案

## 一、定位
为玩家机甲增加 2 个主动技能（喵能炮伤害/重甲护盾减伤），让战斗升级为"移动+自动攻击+主动技能"。局内系统，不持久化养成。不破坏任务1~4 的 110 测试。

## 二、SkillConfig（新增 src/data/SkillConfig.ts）
```ts
type SkillType = 'damage' | 'shield'
interface SkillConfig { id, name, description, type, cooldown, duration?, damage?, range?, radius?, damageReduction? }
```
- meow_cannon：damage, cd 6s, damage 35, range 120（前方扇形/矩形）, 半角 45°
- heavy_shield：shield, cd 10s, duration 3s, damageReduction 0.5
SKILL_CONFIGS 注册表 + getDefaultSkillIds()

## 三、SkillState（新增 src/player/SkillState.ts）
局内运行时状态，纯逻辑可测：
```ts
interface RuntimeSkillState { skillId, cooldownRemaining, activeRemaining, isActive }
class SkillState {
  constructor(configs: SkillConfig[])
  canUse(skillId): boolean
  use(skillId): { ok, started }  // 进入冷却/激活，不直接造成伤害（伤害由 BattleManager 判定）
  update(dt): void  // 衰减 cooldown/active
  get(skillId): RuntimeSkillState
  reset(): void  // 新战斗重置
}
```
设计原则：SkillState 只管时间状态；命中判定/减伤在 PlayerMecha/BattleManager，便于测试。

## 四、PlayerMecha 集成
- 持有 skillState: SkillState
- 新增 facing：朝向角（弧度），默认 0（右）；移动时更新为 atan2(moveY,moveX)；autoAttack 命中时也更新
- 新增 shieldActive getter（skillState.isActive('heavy_shield')）
- takeDamage：若 shieldActive，伤害 ×(1-damageReduction)
- useSkill(skillId, enemies)：喵能炮 → 算前方扇形命中 → 对命中敌人 takeDamage；护盾 → 仅激活（无伤害）
- 暴露 meowCannonEffect（炮口闪光计时 + 命中范围显示计时）供 render

## 五、SkillRenderer（新增 src/render/SkillRenderer.ts）
- drawMeowCannonEffect：橙黄能量光束（朝向方向矩形）+ 炮口闪光圆
- drawShieldEffect：蓝色半透明护盾环（呼吸）+ 受击蓝闪
- 输入 player 状态 + time，纯绘制

## 六、BattleManager 接入
- start：玩家 skillState 已在 PlayerMecha 构造时初始化（新战斗=新 PlayerMecha=新 SkillState，天然重置）
- update：player.updateSkills(dt)（衰减）；渲染技能特效
- usePlayerSkill(skillId)：调 player.useSkill，返回 SkillUseResult
- getPlayerSkillStates()：给 BattleUI
- 胜负后 usePlayerSkill 拒绝（ended 标志）

## 七、BattleUI 技能按钮
- 右下角两个圆形按钮（避开摇杆）：喵能炮/重甲护盾
- 状态：可用高亮/冷却置灰+倒计时/激活蓝光
- 点击：通过 GameManager.usePlayerSkill（GameManager tick handleClick 路由）
- 键盘 1/2（PC 调试，Input 已有 attachKeyboard）

## 八、GameManager
- usePlayerSkill(skillId)：委托 battle.usePlayerSkill（非 battle 场景拒绝）
- BattleUI 的技能按钮点击在 main.ts tick 里处理（或 BattleUI.handleClick）

## 九、SkillUseResult
```ts
{ ok: boolean, reason?: 'cooldown'|'not_found'|'battle_ended', hitCount?: number, damageDealt?: number }
```

## 十、存档
任务文档允许不持久化技能养成。采用：**技能默认全解锁，局内状态，不写存档**。成果说明中明确。避免 PlayerData 改动引出的迁移测试风险。

## 十一、兼容
- 旧 PlayerMecha 构造签名不变（技能内部初始化）
- takeDamage 签名不变（内部判断护盾）
- 旧测试不退化
