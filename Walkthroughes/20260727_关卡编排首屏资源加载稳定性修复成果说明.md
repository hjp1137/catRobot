# 关卡编排首屏资源加载稳定性修复成果说明

## 根因

关卡编排页首次进入时，对所有图层和角色资源无上限并发加载缩略图；任一临时请求失败会直接固化为 `missing`，页面没有原图回退。

## 修复

- 新增 `StageArtLoader`，以最多 4 个并发请求加载去重后的 Art Key。
- 缩略图请求失败时自动改取同资源原图；两种地址均失败才显示 `Missing / Invalid`。
- 编排页继续复用已有资源列表和 API，不改动资源版本、发布快照或关卡数据。

## 验证

- 新增回归：缩略图临时失败回退原图；并发请求不超过设定上限。
- 管理端全量测试：20 文件、73 用例通过。
- 管理端类型检查和生产构建通过。
- `npm.cmd run check:art`：0 Missing、0 Checksum、0 Dimension 错误。

## 使用

刷新关卡可视化编排台即可生效；只有缩略图与原图均无法读取时，才保留 `Missing / Invalid` 提示。
