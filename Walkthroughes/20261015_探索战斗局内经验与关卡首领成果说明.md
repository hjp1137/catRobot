# 探索战斗、局内经验与关卡首领成果说明

日期：2026-10-15。交付：Godot Windows 工程。

## 实际玩法

第一章十关的宽、高分别扩大3倍，面积扩大9倍；各关保留主题，新增远处分区、道路和遮挡，障碍数为29～65。所有可走网格连通，目标平台可达；首关依次探索的三段最短路线合计约22266px。十关配置详情见[地图与首领设计](../docs/design/20261015_探索地图分区与关卡首领配置.md)。

每局流程为：探索两处中继 → 击败各自守卫 → 在光圈内累计稳定能量8秒 → 前往首领区 → 击败首领通关。两处中继可以自行选择先后；离开光圈保留已有进度，暂停和强化选择期间不充能。每处完成恢复35%最大装甲一次。

远处守卫驻守本区，接近才交战，离开会归位。巡游敌人按时间补充并限制存活数量；原地清杂兵不会通关。两处中继完成后，接近首领区才召唤本关首领。

十关分别为赤炉、锈牙、铁齿、雷核、断臂、磁爪、霜牙、熔牙、铁哨、鼠王，使用现有首领机甲美术及分阶战斗数值。首领死亡立即获胜，允许场上杂兵存活；玩家和首领同帧死亡判失败。结束、结算与首领召唤均防重复执行。

## 局内经验与预期

- HUD显示独立局内等级、当前经验、升级需求及蓝色进度条。
- 普通击杀10经验，中继守卫20经验；首轮需120，之后150/180/210逐级增加。
- 满条立即升一级并弹出三选一强化；扣除本级需求、保留溢出经验，选择后恢复战斗，不二次加级。
- 初始3只巡游敌人，每7秒补2只；局内升级后每6秒补2只。供给节奏控制强化频率，没有“满条还等冷却”的隐藏限制。
- 局内等级、经验和强化在新一局重置，营地养成与装备/符文存档不变。

HUD任务文字、世界光圈、屏幕方向箭头及大小地图标记共同指引目标；大地图可点击中继位置规划路线。首领出现后显示名称及独立血条。

## 完整首局节奏测量

使用新建tmp存档和初始属性（120HP、移速220、初始内置机炮），由脚本操作移动、技能及强化选择，按60Hz推进真实战斗逻辑。未注入血量、伤害、击杀、经验、中继完成或首领死亡，也未注入装备。结果如下：

|---|---|
| 通关用时 | 188.00秒，即3分08秒 |
| 第一次强化 | 42.22秒 |

| 第三次强化 | 133.83秒，间隔38.65秒 |

这是完整自动操作模拟的单次测量，真人耗时会随操作、装备和随机强化变化；不是人工游玩或手机真机计时。首关速攻星级放宽为300秒，后续每关+15秒，末关435秒。日志见[pacing_final.log](logs/20261015_expedition/pacing_final.log)，复验脚本为`godot/tests/measure_expedition_pacing.gd`。

## 实现与运行

地图和参数位于`stage_maps.json`；Battle负责探索/经验/首领流程；HUD与地图控件读取实时状态。ContentDB仅覆盖Godot运行时的目标与速度时限，保留原目标ID和奖励关系；Pilot结算支持击败首领目标。未改原发布快照或存档schema。

重启`运行Godot版.cmd`即可载入。完整回归：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-godot.ps1`。后续十关长期装备平衡、真人长局和微信真机仍需继续验证，本次没有据此宣称平台发布验收。
