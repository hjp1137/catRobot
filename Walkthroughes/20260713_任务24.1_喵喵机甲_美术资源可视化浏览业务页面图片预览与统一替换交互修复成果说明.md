# 任务24.1 喵喵机甲美术资源可视化浏览业务页面图片预览与统一替换交互修复成果说明

## 1. 执行结论
- 已将管理端资源页改为默认图库视图，保留表格视图、筛选、搜索、详情、版本历史和草稿/发布对比。
- 已在敌人、背景、主角、关卡列表加入真实缩略图预览；编辑抽屉统一使用可视化资源字段。

## 2. 问题复现
- 修改前 `/content/resources` 默认表格展示，业务页列表仅有 ID、名称、版本、更新时间。
- 敌人、背景、主角编辑抽屉虽有 `ArtResourceSelector`，但字段本身缺少当前图、替换、查看版本、解除绑定等明确语义。

## 3. 实际工程检查结果
- 管理端实际为 `admin/apps/web-antd` Vue3 + Ant Design Vue 子应用，不是完整 Vben 工程骨架。
- 任务24已有资源版本、缩略图、上传、设草稿、删除未发布版本和发布快照能力。
- 远程 MySQL `cat_robot`：`prisma migrate status` 显示 schema up to date，共 3 个 migration。

## 4. 修改文件清单
- 前端组件：`admin/apps/web-antd/src/components/art-resource/*`、`ArtResourceSelector.vue`。
- 前端页面：`ResourcesView.vue`、`EntityListView.vue`。
- 后端：`art-resources.controller.ts`、`art-resources.service.ts`、`stages.service.ts`。
- 测试：`ResourcesView.test.ts`、`EntityListView.test.ts`、`ArtResourceSelector.test.ts`、`stages-service.spec.ts`、`art-resource-versions.spec.ts`。

## 5. 公共组件设计
- `ArtResourceThumb`：固定尺寸缩略图、Missing/草稿/状态标签、加载失败占位。
- `ArtResourcePreviewCard`：图库卡片，展示 Art Key、资源类型、资源包、版本、尺寸、状态和操作。
- `ArtResourceField`：编辑抽屉统一字段，区分选择已有资源、上传新资源、替换当前图片、查看版本、解除绑定。

## 6. 各页面实现情况
- 美术资源：默认图库，表格可切换；详情显示“当前已发布”和“当前草稿”图文对比。
- 敌人：列表按待机、图标、移动优先级展示预览；动作字段使用统一资源字段。
- 背景：列表展示背景/地板等资源缩略图；编辑字段使用统一资源字段。
- 主角：列表按待机、头像优先级展示预览；动作和技能资源字段复用同一组件。
- 关卡：列表展示背景、主角和敌人资源摘要，超过 4 个以 `+N` 表示。

## 7. API 变更
- `GET /content/resources/:artKey/references` 改为真实查询敌人、背景、主角和发布快照引用。
- `GET /content/stages` 返回已有 waves/exploration/objectives 子结构，供关卡列表资源摘要使用。

## 8. 数据库变更
- 无新增 migration，无 schema 修改，无发布快照修改。

## 9. 删除与引用保护说明
- 未发布资源版本删除仍走 `removeDraftVersion`，已发布版本禁止删除。
- Art Key 整体删除/归档未新增绕过入口；详情页显示引用数量，引用接口已不再是占位。
- 编辑抽屉只提供解除绑定，不提供物理删除资源。
