## 三、核心设计实现说明

### 1. 顶部极窄文本条
- **外观**：取消原先的黑色不透明大方框。背景改为薄而通透的 `rgba(10, 14, 26, 0.52)` 微弱背景，并在底部绘制一像素的 `rgba(0, 240, 255, 0.35)` 青色亮线。高度降为 `safeTop + 48`。
- **排版**：
  - 关卡名（`safeTop + 6`），血条（`safeTop + 26`）；
  - 存活数（`safeTop + 6`），金币加成（`safeTop + 26`）。左右对称对齐。

### 2. 左右侧 Dock 悬浮卡片
- **左侧目标 Dock**：自 `safeTop + 64` 起垂直排列 3 个 72x24 像素的卡片：
  - `敌 0/12`（或 `敌√` 时高亮为绿色背景与绿字）；
  - `资 0/3`（或 `资√` 时高亮）；
  - `箱 0/1`（或 `箱√` 时高亮）。
- **右侧导航 Dock**：自 `safeTop + 64` 起展示一个 72x24 像素的青色悬浮胶囊：
  - 根据优先级显示：`清敌`、`找资源`、`开箱`；
  - 目标全清（完成后）自动隐藏。

### 3. 可视安全区约束（解决角色遮挡问题）
- **机制**：通过在玩家被 `clampPlayer` 世界坐标系限制时强行限止其 `y` 坐标不得低于 `safeTop + 48 + 32`。
- **优势**：完美保证了即便玩家在地图最上方行走，其身体最顶端在屏幕上也永远与 HUD 底部保留 `32px` 的清爽空隙，绝对不会造成角色被遮挡。由于是原生移动限制，镜头随之平滑对齐，地图边界 clamp 依旧生效，不露黑边。

## 四、调试探针字段定义说明

我们扩展并充实了 `__MEOW_EXPLORE_TEST_STATE__` 下的几个重要字段：
- `hudMode`: `'edge-minimal'` (全新极简模式标识)
- `hudHeight`: `safeTop + 48` (当前的顶部 HUD 占用高度)
- `hudTopTextOnly`: `true` (标识顶部仅包含文本信息)
- `leftObjectiveDockVisible`: `true` (左侧目标 Dock 面板可见)
- `rightGuideDockVisible`: `!explore.objective.completed` (右侧导航 Dock 在完成时自动变为 false 隐藏)
- `playerScreenSafeTop`: `safeTop + 48 + 32` (玩家在屏幕上的 Y 坐标下限缓冲区)
- `playerScreenY`: `Math.round(explore.player.y - explore.camera.y)` (玩家当前在屏幕坐标上的实际 Y 轴投影)
- `playerOccludedByHud`: `playerScreenY < hudHeight` (若玩家投影低于 HUD 高度则为 true；因已在世界坐标上做了 minY 限制，该判定恒为 `false`)

## 五、用户手动 GUI 测试步骤与截图点位

本任务不要求自动完成微信开发者工具内的 GUI 自动化测试，请您在微信开发者工具中按照以下 10 步进行手动验证：

1.  **准备环境**：在终端执行 `npm run build` 确保编译到最新 JS。打开微信开发者工具并确保其加载了项目。
2.  **进入探索**：在游戏主界面中点击“**自由探索**”按钮。
3.  **顶部文本条截图点**：
    *   **比对标准**：确认屏幕顶部变成了一个扁窄的极简文本条，仅有名称、血量、存活和金币数，且背景通透（仅一根青色底线），绝无黑色实心大面板遮挡。
4.  **左侧 Dock 进度截图点**：
    *   **比对标准**：确认屏幕左侧垂直排列 3 个目标进度小卡片（敌、资、箱）。卡片半透明悬浮且靠边，不影响游戏视野。
5.  **右侧 Dock 导航截图点**：
    *   **比对标准**：确认屏幕右侧出现小型下一步行动指示卡片（如显示“`清敌`”或“`找资源`”），外观小巧，没有多余的长箭头。
6.  **玩家顶部不遮挡截图点**：
    *   **操作**：控制机甲向上移动到训练场地图的最上边缘。
    *   **比对标准**：确认角色即便顶着地图上边界走，在屏幕呈现上也始终处于 HUD 的下方（留出约 30px 空隙），角色全身完全可见，且地图上边缘正常贴合屏幕、相机无抖动、不露黑边。
7.  **边缘箭头避让校验**：
    *   **操作**：向左或向右跑开，使被引导目标（敌人或资源）处于屏幕外。
    *   **比对标准**：观察屏幕侧边的指示箭头。确认当箭头投影在左右两侧悬浮 Dock 时，会自动被向下方排推，完全不遮盖悬浮 Dock。
8.  **目标进度变化校验**：
    *   **操作**：击杀敌人，或者拾取资源。
    *   **比对标准**：确认左侧对应的“敌”或“资”的计数能够实时发生变化，当击杀达到 12/12 时，卡片高亮为浅绿色且字样变为“`敌√`”。
9.  **全目标完成截图点**：
    *   **操作**：达成 12/12 击杀、3/3 资源与 1/1 宝箱。
    *   **比对标准**：确认屏幕中心弹出科幻质感的“`★ 训练完成 ★`”大控制面板。此时观察左右侧，右侧的导航卡片已完全自动隐藏。
10. **固定屏 1-1 隔离校验**：
    *   **操作**：返回主页，点击“**战斗测试**”进入 1-1。
    *   **比对标准**：确认 1-1 战斗场景顶部的波次 HUD 和敌人 HUD 正常显示，且屏幕左右两侧绝对没有任何“敌、资、箱”等悬浮 Dock 元素。
