# 四向跑步摆臂投影与尾巴收形

日期：2026-10-20。处理用户对正式游戏摆手幅度、正背/斜向跑姿及尾巴过大的反馈。

## 已修改

- 摆臂先在前后/竖直平面求两段手臂屈伸，再按实际移动方向投影。正背面不再把前后摆动画成左右扇动，斜向也不再只读取脚的横向坐标。
- 从脚点移除抬脚高度后再计算前后摆动，避免斜向手臂被抬脚的屏幕Y变化带偏。
- 收敛侧面摆幅，跑步适度屈肘；按弯肘后的腕部合方向校正肩部角度。正背面肘部略在肋侧，前臂轻微向胸侧回收，避免腕点只是机械直上直下。
- 保持手腕、武器挂点与各自装备身份；上臂/前臂护甲跟随投影缩短，解决背面前臂变短而护甲伸过手腕的问题。完整装备贴图保留。
- 尾巴从115×137改为侧面76×100、正背面70×100；保留尾根、毛发素材、镜像和层级。游戏与机库共用身体分件，因此同步生效。
- 未修改行走速度、地图碰撞、足部接地曲线、装备数值或辅助四向预览功能。

## 验证

- 新摆臂检查先在旧动作上复现失败：28 PASS / 28 FAIL；穿甲投影另有59/3红例，实际护甲曾超出前臂终点约35–39源像素。
- 最终导入通过，8组检查 **1814 PASS / 0 FAIL**：摆臂62、节奏79、自然动作261、斜向214、模块动作279、外观UI198、双武器156、营地565。
- 静态完整周期测量：侧面空手腕横向跨度154.81→94.99；正面空手腕纵向跨度6.31→36.44、横向跨度20.32→14.58。单位均为角色源坐标，不是屏幕像素或真实人体数据。
- 只读探针另检查10方向配置×空手/持械，以及8次连续转向，未见前臂翻折或左右身份互换；最终效果仍以本次实际GPU画面为准。

## 图形检查范围

- 正面、背面、左、右及四个斜向；混装斜跑、全甲正面/背面/侧面。每段包含慢走、奔跑、停步、重开和再停。
- 采样走真实Battle键盘输入、地图通行和位移逻辑，使用临时存档；机库另留实际画面检查尾根和体量。
- 左下斜跑两帧远脚被近腿正常遮住。独立重建中正常图远脚差值0/0，隐藏近腿后差值44/58，证明远脚仍在地板上正常绘制。
- 本轮临时采集只对真实远脚/近腿关系做隔离复核，原RGB差值>0.08、像素>2不变，恢复图像ROI必须逐字节一致；不按方向或帧跳过失败。
- 一次长批次中，左上段出现13个无位移控制步，随后Godot原生进程异常退出。Windows事件1000/1001记录异常0xe06d7363、模块KERNELBASE.dll；没有足够信息确定根因，也不认定为已修复的游戏或引擎故障。
- 保留中断日志，采样改为每帧重申测试按键状态，按四向/斜向/装备分成三个独立进程复核。最终输出只收录完整通过批次，未用中断片段拼接成通过记录。
- 三个最终GPU批次分别2453/0、2455/0、2406/0，合计 **7314 PASS / 0 FAIL**；覆盖3024个60Hz控制步、1512张30fps采样帧。
- 12段视频全部完成126帧解码及尺寸、源图差值和运动帧重复检查；浏览器确认12段均为320×260、4.2秒，半速和逐帧操作通过，控制台与页面异常为0。
- 人工查看正面、背面、两组斜向关键帧，以及全甲背面和机库图：前臂护甲随投影缩短，手腕与武器衔接，尾根连续且体量减少。关键帧检查不能替代完整动画的主观体验判断。
