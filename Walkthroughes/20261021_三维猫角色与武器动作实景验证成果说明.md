# 三维猫角色与武器动作实景验证

日期：2026-10-21。用户授权采用三维猫角色与现成动作库，保留二维地图和玩法，先验证六类武器。

## 实现

- `CombatActor` 的正式玩家及营地玩家采用透明 SubViewport 中的三维猫，二维地面位置、地图碰撞、路径、排序、血量、装备数值和独立射击流仍由原逻辑负责。
- 猫外观保留灰棕虎斑、白胸腹、蓝绿色眼睛、猫耳、猫嘴、猫爪和细尾；本轮是平滑卡通三维造型，不是原二维毛发贴图的等质感立体化。躯干使用连续蒙皮，装备按原槽位显隐与配色。
- 导入 Quaternius Universal Animation Library Standard，CC0，65根骨骼、43个片段；使用现成待机、走路、慢跑、冲刺、手枪持握、射击与受击动画。
- 从 Godot 官方第三人称演示重定向7个战斗片段：前后/左右移动、持械走跑与战斗待机；保留CC-BY 3.0作者署名。源角色是手臂炮机器人，不能把它宣称为现成的六类武器专业动作套装。
- AnimationTree 处理走跑、战斗方向、上下身及射击/受击叠加；手部约束把六类武器的实际握点连接到掌心，尾巴与装备跟随骨架。
- 第一发及骤然反向目标先同步真实枪口朝向，再创建弹丸。二维逻辑弹丸位置保留，绘制位置从真实枪口出发，过渡到敌人躯干；符文派生弹使用同一显示偏移。
- 双枪保留各手真实武器类型、颜色与独立枪口；修正过左右枪共享主手颜色的问题。
- 长枪采用胸前贴肩、重炮低托宽肘、发射器靠肩携行与抬射、双枪两侧分开的姿势；手枪和持盾组合分别处理空闲手及举盾。
- 猫爪改为扁掌与足趾骨附件；动画之后做真实大腿/小腿两节接地修正，保持脚踝朝向、腿长和骨盆位置。移动时只消除穿地，明确静止时才允许少量向下落脚。

## 验证入口

- 根目录 `运行3D动作验证.cmd`，启动原 `main.tscn` 与第一关正式战斗场景。
- 数字1–6依次试装短枪、长枪、双枪、重炮、盾牌加短枪、发射器，每次重开本局。
- WASD移动，自动攻击，空格为原技能炮，E为原护盾技能，F10退出。
- 使用仓库tmp中新建隔离存档；试装只修改本局表现与匹配的一/二条射击流，不写入用户原存档、装备、掉落或永久数值。
- 盾牌验证展示持盾和举盾姿势，防御仍由原E技能触发；没有擅自新增持盾永久防御或装填玩法。

## 验证记录

- 初始场景红例：正式玩家尚无三维接入，0/1失败；导入时另发现Godot自动移除 `_Loop` 后缀，按实际导入名称修正。
- 双持颜色探针修前5/3，修后8/0；实际左右材质颜色及独立性通过。
- 首发反向审查曾复现枪管与绘制弹道夹角150.52度；已增加方向检查，正式场景四向瞬时换目标与握持检查通过。
- 原二维分件专用走跑检查不再作为正式三维角色验收；默认验证入口已改用三维场景及动作行为检查，保留旧文件作为原实现历史验证。
- 图形采样走原Main/Battle、键盘移动、地图通行、自动射击与弹丸伤害；受控60Hz步进与30fps采样不代表实时性能或手工长期游玩验收。
- 最终新鲜导入及9组 **1824 PASS / 0 FAIL**：三维场景97、动作586、战斗46、双武器156、移动22、动作/地形113、外观UI198、营地565、符文战斗41。最终日志未见脚本错误、引擎错误或资源泄漏。
- 真骨架握持探针108/0，目标方向探针576/0；最后瞄准样本最大枪管角误差约0.0615度、握点误差不超过0.000001米。探针不替代正式场景检查。
- 同相位脚掌对照：最深穿地约-7.25cm改善至不低于地面；普通/战斗静止时实际脚掌下缘约3mm，骨盆位移差为0，腿长保持。正式96组动作及穿靴复核通过，阈值已由8cm穿地收严至1cm。
- 最终受控GPU三批分别3012/0、3012/0、584/0，合计 **6608/0**、912帧，覆盖六类武器及八方向。
- 另采集原第一关正常物理更新12.57秒：保留5个原始敌人、默认武器，无注入靶子或强制击杀；180张采样中19张存在活动弹丸，生命120→99，实际战斗与受伤发生。
- 8段WebM共1092帧全部解码，尺寸和源图差值检查通过；浏览器8段加载、半速与逐帧操作通过，页面/控制台0错误。自然战斗片段按采样期间游戏时间回放，不是性能基准。
- 实际Windows启动器静音检查6/0，退出无错误；交互模式保留原音效。此前射击音效退出的偶发释放警告未被认定为已修复。
- 人工查看最终关键帧及发射器/背向移动截图，未见明显脚踝脱节或武器破碎；前景地物会正常遮挡部分肢体。单帧和自动检查不能证明所有视角无穿插或步态达到最终美术验收。
