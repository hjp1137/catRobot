# 任务22后台登录表单校验无响应修复成果说明

## 1. 问题现象

- 管理端登录页输入用户名和密码后点击登录，仍显示 `username is required` 与 `password is required`。
- 后端 `/api/health` 正常，问题发生在前端提交前的表单校验阶段。

## 2. 根因

- `LoginView.vue` 中 `a-form-item` 配置了 `name="username"` 与 `name="password"`。
- 外层 `a-form` 未绑定 `:model="form"`，Ant Design Vue 校验无法读取输入框的实际值。
- 校验失败后 `@finish="submit"` 不触发，因此表现为点击登录无反应。

## 3. 修复

- 修改 `admin/apps/web-antd/src/views/content/LoginView.vue`，为 `<a-form>` 增加 `:model="form"`。
- 新增 `admin/apps/web-antd/src/views/content/LoginView.test.ts`，锁定登录表单必须绑定模型。

## 4. 验证

- 修复前 `pnpm.cmd --dir admin test` 失败，确认缺少 `:model="form"`。
- 修复后 `pnpm.cmd --dir admin test` 通过，3 个测试通过。
- `pnpm.cmd --dir admin typecheck` 通过。
- `pnpm.cmd --dir admin build` 通过，仅保留 Vite chunk size 警告。
- `http://127.0.0.1:5602/` 返回 200。
- `http://127.0.0.1:3100/api/health/database` 返回 MySQL 8.0.33 与 `cat_robot`。

## 5. 注意

- 若页面仍显示旧校验状态，刷新管理端页面后再试。
- 若提交后显示“登录失败”，说明表单已提交到后端，需要确认管理员账号是否已创建或密码是否正确。
