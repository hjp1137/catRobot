# 正式战役节点解锁链路修复成果说明

## 问题

铸造通道完成后，地图仍将“边境训练场”显示为锁定。旧结算链只解锁 `1-2`，与发布战役地图使用的 `explore_training` 不一致。

## 修复

- 自由地图完成时生成发布结算需要的内容节点 ID 与运行结果。
- 结算复用已有发布进度、奖励和解锁规则，正确解锁 `explore_training`。
- 游戏启动时依据历史通关记录补齐遗漏的发布节点解锁，不重复奖励。

## 验证

- 新增“正式战役完成解锁下一节点”和“历史三星存档补齐解锁”回归测试。
- 专项30项、全量570项测试和类型检查通过。

## 使用

在微信开发者工具点击“普通编译”。已有首关三星记录会自动解锁边境训练场；新完成铸造通道也会立即解锁。
