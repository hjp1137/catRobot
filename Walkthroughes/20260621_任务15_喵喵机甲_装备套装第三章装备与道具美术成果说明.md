# 成果说明：装备套装与第三章装备道具美术成果说明 (任务 15)

本成果说明记录了第三章熔岩装备套装、火抗符文、UI 自适应排版、存档防错迁移以及自验证测试。

## 一、 目标与完成内容
- **目标**：增量实现熔岩装备套装与第三章装备、道具美术资源及 UI 自适应展示。
- **完成内容**：
  1. 注册 `lava_cannon` (史诗武器)、`lava_armor` (史诗装甲)、`lava_core` (史诗核心)。
  2. 实现 2/3 件套装效果 (战力 30/50，火抗 15%，冷却 5%，加伤 10%)。
  3. 注册优秀品质火抗符文 `fire_guard_rune`。
  4. 支持装备面板 UI 根据套装件数自适应高度，置灰/高亮展示激活状态与套装标识。
  5. 优化 `SaveManager` 存档防错迁移机制，过滤悬挂装备及超额或脏符文配置。
