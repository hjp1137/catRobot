# 关卡编排阻挡区拖动与缩放修复成果说明

## 交付

- 选中阻挡区后，拖动矩形内部可移动区域。
- 矩形四角与四边均提供缩放控制点，缩放时对边/对角保持锚定。
- 拖动过程只在画布预览；松开后一次写入现有草稿、撤销/重做和保存链路。
- 坐标仍使用当前关卡画布和网格吸附，矩形不会越出画布。

## 使用

1. 在“关卡编排”选择一个阻挡区。
2. 直接拖动框内移动；拖动黄色小方块调整尺寸。
3. 如需完全重画，点击“框选区域”。
4. 确认右侧属性后保存草稿、校验、发布。
