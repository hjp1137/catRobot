# 自由探索敌人自主巡逻与阻挡区避让修复成果说明

## 修复结果

- 初始生成、正式波次生成和后续补怪统一读取发布地图 `terrainObstacles`。
- 候选出生点会校验玩家安全距离、世界边界和实体碰撞，不再把敌人生成到设备内部。
- 巡逻目标会过滤落入阻挡区或直线路径穿过阻挡区的位置，避免状态显示移动但坐标被碰撞系统持续回滚。
- 警戒、追击、攻击、刷新数量、碰撞半径及发布地图数据未改。

## 验证证据

- 修复前稳定复现：7 只初始敌人中 `spawn_c03`、`spawn_d04` 各有一只出生在碰撞体内，5 秒实际位移均为 0。
- 修复后相同场景：阻挡区内出生数为 0；角色远离时 7 只敌人 5 秒位移分别为 55.5、134.4、55.1、100.6、154.6、28、136 像素。
- 新增回归测试覆盖“出生位置可通行”和“未发现角色时每只敌人持续产生位移”。
- 微信开发者工具重新编译并进入自由探索；静置观察到可见敌人离开初始位置，靠近警戒范围后正常切换战斗并被自动射击击杀。
- `npm test`：576 项通过，0 项失败。
- `npm run typecheck`、`npm run check:art`、`npm run check:animation`、`git diff --check`：通过。

## 边界

- 本次修复自主巡逻的出生与目标可达性，不新增复杂寻路系统，也不改后台发布快照。
