# 任务6 成果说明：喵喵机甲 技能养成与机甲成长扩展

日期：2026-06-19

## 一、任务目标
把任务5局内技能扩展为持久化养成（等级1~5，消耗金币/零件升级，效果随等级成长），加技能养成界面 + 战力含技能贡献 + 主界面成长展示。形成完整 RPG 成长循环：闯关→资源→升级机甲/技能→战力提升→挑战更难关卡。不破坏任务1~5 的 135 测试与旧存档。

## 二、完成内容
- **SkillConfig 重构为等级成长**：effects[]（5级伤害/范围/冷却/持续/减伤）+ upgradeCosts[] + maxLevel=5；工具 getSkillEffect/getSkillUpgradeCost
- **PlayerData 持久化技能**：unlockedSkillIds + skillLevels；SaveManager 迁移（补默认/缺字段/钳制1..maxLevel）
- **SkillUpgrade 纯逻辑**：getSkillLevel/getSkillEffectForPlayer/getSkillUpgradePreview/tryUpgradeSkill
- **战力扩展**：PowerCalc（基础战力 + 技能战力=各技能等级×20）；GameManager.totalPower
- **战斗接入等级**：SkillState 按等级 effect 初始化 cooldown/duration；PlayerMecha 构造接收 skillLevels，喵能炮伤害/范围/半角 + 护盾减伤均读当前等级 effect
- **技能养成界面**：SkillPanelUI（技能卡：名称/等级/当前效果/下级预览/消耗/升级按钮/满级置灰/资源不足提示）
- **主界面成长展示**：技能摘要（喵能炮 Lv.X · 重甲护盾 Lv.X）+ 战力用 totalPower + 技能养成入口按钮

## 四、技能升级规则
- tryUpgradeSkill：未解锁/满级/金币不足/零件不足 拒绝（不扣费）；足够则扣费+等级+1
- 满级（=5）不可升级；升级后立即落盘（GameManager.doUpgradeSkill → SaveManager.save）
- 升级预览 getSkillUpgradePreview 供 UI 展示当前/下级/消耗/是否满级

## 五、技能养成界面说明
- 场景 skillPanel，主界面「技能养成」按钮进入
- 两张技能卡：名称+Lv.X/maxLevel、当前效果、下级效果预览（绿色）、消耗（金币/零件圆点）、升级按钮
- 满级显示「已满级」置灰；资源不足显示「资源不足」置灰；点击升级后立即刷新+toast 提示
- 返回车库按钮回主界面

## 六、机甲成长与战力计算说明
- 基础战力 = 生命 + 攻击×10（机甲等级派生，不变）
- 技能战力 = 各已解锁技能等级 × 20（喵能炮+重甲护盾）
- 总战力 = 基础 + 技能；GameManager.totalPower
- 主界面战力、关卡选择/介绍推荐战力对比均用 totalPower
- 技能升级或机甲升级后战力提升

## 七、存档迁移说明
- PlayerData 新增 unlockedSkillIds（默认全解锁）、skillLevels（默认全1）
- SaveManager.migrate：旧存档无字段补默认；skillLevels 缺某技能补1；<1 修正1；>maxLevel 修正 maxLevel；脏存档回退默认
- 局内状态（冷却/激活）不写存档，只持久化解锁与等级
