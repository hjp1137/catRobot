# 任务24.1.1 业务页资源字段 Missing 二次修复成果说明

## 1. 现象
- 敌人、背景、主角、关卡等业务页的预览和编辑抽屉仍显示 `missing`。
- 截图中的 Art Key 为 `enemy.scrapMouse.normal`，但字段组件未拿到草稿版本、发布版本、尺寸和缩略图。

## 2. 根因
- 后端 3100 资源接口已返回正确摘要：`enemy.scrapMouse.normal` 为 `physical`，包含 `thumbnailUrl`。
- 远程 MySQL 中敌人、主角、地图样例资源均为 `physical`，不是数据缺失。
- 业务页公共链路依赖父级 `artResources` 列表按 `item.art_key` 匹配；当列表未命中、字段初始渲染或返回形态不一致时，`ArtResourceField` 和 `ArtResourceThumb` 直接 fallback 为 `missing`。

## 3. 修复
- `EntityListView` 向所有业务预览和编辑字段传入原始 Art Key。
- `resourceForKey` 兼容 `art_key` 与 `artKey`，并对 Art Key 做 `trim` 归一。
- `ArtResourceField` 在父级未传入 resource 时，按 `modelValue` 单独请求 `/content/resources/:artKey`。
- `ArtResourceThumb` 在父级未传入 resource 时，按 `artKey` 单独请求资源摘要。
- 当父级有 resource 但缩略图 Blob 缺失时，字段和缩略图组件会按 `thumbnailUrl` 再拉一次图片。
- 预览打开逻辑在父级列表未命中时，也会按 Art Key 单独获取资源摘要。

## 4. 覆盖范围
- 敌人管理列表预览和编辑抽屉。
- 背景主题列表预览和编辑抽屉。
- 主角表现列表预览和编辑抽屉。
- 关卡配置资源引用汇总。
