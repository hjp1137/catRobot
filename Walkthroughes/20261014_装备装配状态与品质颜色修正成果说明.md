# 装备装配状态与品质颜色修正成果说明

日期：2026-10-14。范围：Godot机甲、背包、装备详情及套装图鉴的显示。

## 修正结果

- 空槽采用更暗底色、细灰边框和22%透明占位图标，显示“空槽/未装配”；点击仍进入对应部位筛选。
- 已装配槽显示彩色真实装备、3px品质边框、品质色名称和“已装配”标记；点击仍打开原装备详情。
- 未穿戴套装的中央角色注明“基础机体”；双手均空时明确显示内置机炮，不当作已装配武器。
- 背包名称、等级文字、网格边框、详情边框和品质说明统一取显示色；选中使用独立小标记。
- 槽位、网格和图鉴在normal/hover/pressed/focus状态保留品质色，不再被橙色选中框或青色悬停框覆盖。

| 装备等阶/品质 | 显示色 | 色值 |
|---|---|---|
| 普通 | 白 | #edf4fc |
| 黑铁 | 绿 | #52de8a |
| 青铜 | 蓝 | #56a9ff |
| 白银 | 紫 | #be86ff |
| 黄金 | 金 | #ffd166 |
| 星辰 | 红 | #ff667f |
| 旧稀有/旧史诗 | 蓝/紫 | 与青铜/白银一致 |

先按真实tier取色；无tier的旧装备按rarity取色，未将旧稀有/史诗降为普通。
项目允许保留未知旧配置，其缺少rarity；现在使用中性色和未识别提示，避免显示时访问不存在的字段。

## 根因与实现

原空槽与装备使用相同填充，并直接显示彩色占位图标；缺少tier的旧装备一律返回灰蓝。
背包选择和悬停又分别用橙/青色覆盖装备边框，进一步掩盖装备等阶。

- `equipment_art.gd`：独立UI调色板，按装备tier/rarity统一取色和品质名称。
- `inventory_ui.gd`：区分槽位状态；统一卡片交互态、背包标记、详情和共鸣/图鉴色。
- `equipment_details.gd`：装备与套装标题使用真实品质色。
- `test_interface_runtime.gd`：补充未知旧装备装配后存档重载和实际机甲页显示回归。
- `capture_equipment_states.gd`：复用原截图工具生成七种真实运行状态，未新增测试框架。

没有修改rarity、生成器或配置的金属色、战斗着色、装备数值、强化/分解成本和掉落规则。
品质边框属于界面展示，套装原有造型和纹理保留。

- UI自然战斗/生命周期：74通过、0失败。
- 真实界面按钮与兼容状态：182通过、0失败。
- 合计256通过、0失败；使用各自新建独立临时存档，没有读取或改写玩家真实存档。
