日期：2026-06-18

## 一、任务目标
从单关卡 MVP 扩展为第一章可推进的闯关原型：多关卡配置 + 关卡选择界面 + 解锁链 + 通关记录 + 星级评价 + 首通/重复奖励区分 + 旧存档迁移。不改玩法核心、不破坏任务1/1.1/2 的 53 个测试与旧存档。

## 四、进度系统说明
- **默认状态**：新存档仅解锁 1-1
- **解锁链**：通关第 N 关后自动解锁第 N+1 关（unlockAfter 配置驱动）
- **通关记录**：stageProgress[stageId] = { cleared, bestStars, clearCount, firstClearedAt, lastClearedAt }
- **迁移**：旧存档（任务1/2 无进度字段）加载时自动补 stageProgress={}、unlockedStageIds=['1-1']
- **持久化**：进度写入 wx storage，关闭重开不丢失

## 五、奖励与星级规则
**星级**（胜利才计算，上限 3）：
- 基础 1 星
- 剩余血量 ≥ 50%：+1 星
- 通关用时 ≤ 60 秒：+1 星
- bestStars = max(历史最高, 本次)，只增不降

**奖励**：
- 首次通关：100% 关卡奖励
- 重复通关：50%（向下取整）
- 失败：不发奖、不解锁、不记录通关
