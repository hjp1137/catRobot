## 三、波次系统说明
- StageConfig 支持 enemies[]（单波，向后兼容）与 waves[]（多波）二选一；WaveManager 无 waves 时自动转单波
- 当前波敌人全部死亡 → 等待 spawnDelay → 生成下一波；波次切换显示 message 提示 2 秒
- 最后一波清空 → isLastWaveCleared=true → BattleManager 判胜利
- 1-5 三波：前哨巡逻(4鼠) → 强化守卫(2强化鼠, 延迟1.2s) → 鼠王登场(1鼠王, 延迟1.5s)

## 四、Boss 关机制
- 1-5 标记 isBossStage=true，关卡选择/介绍显示 Boss 标识
- Boss 登场后 BattleUI 显示专属血条（红色，带 Boss 名「机械鼠王」）
- Boss 死亡 → 血条隐藏；全波清空 → 胜利结算
- 召唤小鼠：Boss hp<50% 时通过 onSummon 回调让 BattleManager 生成 2 只机械鼠，每场最多 1 次

## 五、Boss 技能说明
**震荡冲击 Shockwave**（状态机）：
- idle(5s 冷却) → warning(1s，红色脉动预警圈跟随 Boss，**不造成伤害**) → blast(瞬间判定：玩家在中心半径90内 → takeDamage 12，扩散金色环) → cooldown(5s) → idle
- blast 每次只判定一次伤害（blastHit 标志防重复）
- Boss 死亡 → 技能 disabled，停止

**召唤小鼠**：Boss hp<50% 且本场未触发 → 召唤 2 只机械鼠，每场最多 1 次。

## 六、关卡介绍与章节完成提示
- 主链路：主界面 → 关卡选择 → **关卡介绍**(stageIntro) → 开始挑战 → 战斗 → 结算 → 返回关卡选择
- StageIntroUI 显示关卡信息；Boss 关额外显示「⚠ BOSS 关 ⚠」
- 首次通关 1-5：结算界面显示「★ 第一章完成！★ 废弃训练场已清理 · 新的区域即将开放」
- 重复通关 1-5：不再显示章节完成（chapterCompleted=false）
- 第一章完成由「1-5 首次 cleared」推导，无需新增持久化字段
