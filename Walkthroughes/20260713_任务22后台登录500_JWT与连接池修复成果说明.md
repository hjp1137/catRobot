# 任务22后台登录500 JWT与连接池修复成果说明

## 1. 问题现象

- 管理端登录请求已能发出，但 `/auth/login` 返回 500。
- 浏览器 Network 仅显示 `Internal server error`。

## 2. 根因

- `server/.env` 中 `JWT_SECRET` 为空，账号密码校验通过后签发 JWT 时抛出异常。
- 远程 MySQL 同时出现 `Too many connections`，独立调试脚本和账号创建脚本无法稳定获取新连接。

## 3. 修复

- 为 `server/.env` 生成本机随机 `JWT_SECRET`，未输出密钥内容。
- 为 `DATABASE_URL` 增加 `connection_limit=1` 与 `pool_timeout=10`。
- 同步更新 `server/.env.example` 与后台使用说明中的连接串示例。
- 重启后端服务，使新配置生效。

## 4. 验证

- 后端 `/api/health` 返回正常。
- 临时管理员账号创建成功，登录成功签发 token，验证后已删除临时账号。
- 截图中的 `adminHjp1137` 账号存在，角色为 admin，状态为启用。
- 后端服务已恢复运行。

## 5. 注意

- 若继续提示登录失败，应检查当前输入的密码是否与 `adminHjp1137` 账号一致。
- 如需重置密码，可执行 `npm --prefix server run content:admin:create-user -- adminHjp1137 新密码 admin`。
