# Battle Asset Slots

These folders reserve the replacement path for Task 12 battle visuals.
Current runtime still uses the existing flat `assets/*.png` resources through `src/config/BattleAssets.ts`.

- `player/`: player mecha cat sprites.
- `enemies/`: normal, elite and boss enemies.
- `bullets/`: basic projectiles and skill shots.
- `effects/`: hit, cast and explosion effects.
- `drops/`: coin and energy drops.
- `ui/`: HUD and skill button art.
- `backgrounds/`: battle scene backgrounds.
