# 喵喵机甲内容模板与关卡配置说明

## 1. 架构

内容主数据源在 `src/content/data/*.ts`，由 `LocalContentRepository` 加载到 `ContentRegistry`。运行时通过 StageDefinition 解析敌人、背景和主角表现。物理图片路径仍由 `ArtManifest` 和 `ArtResourceResolver` 处理，内容配置只写 Art Key。

## 2. EnemyTemplate

文件：`src/content/data/enemies.ts`。

- `id/name/category/behaviorType`：敌人身份与行为分类。
- `visual`：敌人图标、待机、移动、攻击 Art Key、显示比例和碰撞半径。
- `stats`：`maxHp`、`attack`、`defense`、`moveSpeed`。
- `combat`：攻击间隔、攻击范围、索敌范围、追击范围。
- `enabled/version`：启用状态与版本。

新增敌人：复制一个模板，换唯一 `id`，填写数值和 Art Key。修改血量、攻击、速度：改 `stats.maxHp`、`stats.attack`、`stats.moveSpeed`。替换美术：改 `visual.idleArtKey` 等字段，不改渲染器。

## 3. BackgroundTheme

文件：`src/content/data/backgrounds.ts`。

- `art.floorArtKey/lineArtKey/boundaryArtKey/zoneMarkArtKey`：背景主题使用的 Art Key。
- `rendering.mode`：`stretch`、`cover`、`tile`、`world-tile`。
- `showGrid/showZoneMarks/showBoundary`：控制网格、区域标记和边界显示。

新增背景主题：新增一项 `BackgroundTheme`。让关卡使用新背景：在 `src/content/data/stages.ts` 修改 `backgroundThemeId`。

## 4. HeroVisualTemplate

文件：`src/content/data/heroes.ts`。

- `visual`：主角待机、移动、攻击 Art Key、显示比例和碰撞半径。
- `skills`：护盾、喵能炮按钮图标和效果 Art Key。

新增主角皮肤：复制 `hero_mecha_cat_default` 并更换 Art Key。指定关卡使用皮肤：修改 StageDefinition 的 `heroVisualTemplateId`。

## 5. StageDefinition

文件：`src/content/data/stages.ts`。

- 固定屏关卡：`mode: 'fixed-battle'`，使用 `waves[].groups[].enemyTemplateId` 绑定敌人。
- 探索关卡：`mode: 'explore'`，使用 `exploration.spawnGroups[].enemyTemplateId` 绑定刷新点敌人。
- `backgroundThemeId` 与 `heroVisualTemplateId` 分别绑定背景主题和主角表现。

给固定屏关卡加敌人：在对应 wave 的 `groups` 中增加 `{ enemyTemplateId, count, spawnGroup }`。给探索关卡加刷新点：在 `spawnGroups` 增加坐标、半径、初始数量、存活上限和刷新间隔。

## 6. 当前迁移范围

- `stage_battle_1_1`：由 StageDefinition 生成旧 `STAGE_1_1` 兼容配置。
- `stage_explore_training_01`：自由探索训练场世界尺寸和 4 个刷新点来自 StageDefinition。
- `StageConfig` 和 `EnemyConfig` 暂作为旧章节、Boss 技能、进度和掉落兼容层，新关卡不应继续扩展旧波次源。

## 7. 校验命令

先构建，再校验：

```bash
npm run build
npm run check:content
npm run check:art
```

`check:content` 会检查 ID、名称、版本、启用状态、数值范围、Art Key、关卡引用、刷新点坐标和禁用模板引用。失败时输出配置文件、对象 ID、字段和原因。

## 8. 后台接入预留

后续后台不需要改运行时查询逻辑，只要新增 `ApiContentRepository` 实现：

```ts
loadEnemies()
loadBackgrounds()
loadHeroVisuals()
loadStages()
```

再将初始化仓库从 `LocalContentRepository` 切换为 API 实现即可。后台保存前应复用 `ContentValidator` 做同等校验。
