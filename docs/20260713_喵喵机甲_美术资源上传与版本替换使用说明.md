# 喵喵机甲美术资源上传与版本替换使用说明

## 1. 入口
- 登录内容管理后台。
- 打开 `内容管理 / 美术资源`。
- 页面展示缩略图、Art Key、资源类型、资源包、草稿版本、发布版本、校验状态和操作。

## 2. 新建 Art Key
- 点击 `新建美术资源`。
- 填写 `artKey`、资源类型、资源包、建议宽高、尺寸策略、Fallback Art Key、透明通道要求。
- Art Key 示例：`enemy.scrapMouse.redArmor`、`player.mechaCat.blueSkin`。
- 创建后 Art Key 不直接改名；如需改名，新建 Art Key 后迁移引用。

## 3. 上传图片
- 在资源列表点击 `上传新版本`。
- 后端只接收服务端生成路径，不接受前端填写物理路径。
- 上传成功后产生新的资源版本，并自动设为当前草稿版本。
- 上传不会立即影响已发布小游戏。

## 4. 替换已有图片
- 搜索现有 Art Key，例如 `enemy.scrapMouse.normal`。
- 上传明显不同的新 PNG。
- 在详情中查看当前发布版本和当前草稿版本对比。
- 执行完整校验并发布后，游戏才会读取新版本。

## 5. 查看尺寸与透明通道
- 详情页版本历史展示实际宽高、checksum、状态和上传时间。
- 精灵、图标、特效类资源通常要求透明通道。
- 背景和地图类资源不强制透明通道。

## 6. 查看校验错误
- 上传时会校验真实格式、解码、尺寸策略、透明通道、像素总数和重复 checksum。
- 完整内容校验会检查内容引用的 Art Key、资源版本、文件存在、checksum 和 fallback。

## 7. 设置草稿版本
- 在版本历史中点击 `设为草稿`。
- 旧版本设为草稿不等于回滚线上游戏。
- 仍需完整校验和重新发布。

## 8. 查看发布版本
- 列表中 `发布 vX` 表示当前小游戏发布版本使用的资源版本。
- `草稿 vX` 与 `发布 vX` 不一致时，页面会提示需要发布后进入游戏。

## 9. 敌人使用新图片
- 打开敌人管理。
- 图标、待机、移动、攻击、受击、死亡、精英光环字段均使用 Art Key 选择器。
- 选择草稿资源后保存敌人，再校验并发布。

## 10. 背景使用新图片
- 打开背景主题。
- 背景、地板、网格线、边界、区域标识字段使用 Art Key 选择器。
- 背景图允许 PNG/JPEG，地图槽位按资源规则校验。

## 11. 主角使用新图片
- 打开主角表现。
- 头像、待机、移动、攻击、受击、死亡、技能图标和技能特效均使用 Art Key 选择器。
- 多个动作暂时共用同一 Art Key 不阻止保存。

## 12. 校验与发布
- 打开校验与发布页。
- 执行完整校验，错误为 0 后发布。
- 发布会生成内容快照、Art Manifest 快照和版本化资源包。

## 13. 历史恢复
- 在发布历史中选择旧版本恢复为草稿。
- 恢复会回填内容配置和对应 Art 版本选择。
- 重新校验并发布后才会生成新的线上版本。

## 14. 常见上传错误
- 扩展名伪造：真实文件签名不是 PNG/JPEG。
- 尺寸不符：`exact` 策略要求完全匹配。
- 缺少透明通道：资源规则要求透明但图片无 alpha。
- 重复上传：同 Art Key 已存在相同 checksum 的版本。

## 15. 限制
- 默认文件大小限制：12 MB。
- 默认像素总数限制：16,777,216。
- 支持 PNG；背景和地图支持 JPEG。
- 不支持 SVG、GIF、BMP、TIFF、PSD、ICO、EXE、ZIP。

## 16. 发布后构建小游戏
- 发布成功后运行 `npm run check:art`、`npm run check:content`、`npm run build`。
- 微信开发者工具刷新项目后，游戏读取 `mysql-published-art-snapshot`。
