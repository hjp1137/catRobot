# 《喵喵机甲》美术风格规范

本文档旨在确立《喵喵机甲》微信小游戏版的整体视觉艺术规范与设计基调。所有美术设计师和素材生成程序在为项目生产资源包时，必须严格遵守本规范，以确保项目整体画风的高度统一与极佳的移动端可读性。

## 1. 整体风格定位
游戏的核心美术风格确立为：**Q版机甲猫 + 赛博训练场 + 轻度废土科幻 + 微信小游戏高可读性**。
- **高对比与卡通化**：游戏面向微信轻度休闲与中度放置玩家，美术资产应可爱、醒目且具有鲜明的辨识度，严禁使用过度写实、阴暗、混乱和复杂的背景及机甲细节。
- **主角设计**：主角应展现为科技感与萌系相结合的“机甲猫”，通过圆润可爱的造型搭配硬核科幻的机动装甲来表达。
- **敌人设计**：敌人（如各种机器变体老鼠）应具有明显的“废铜烂铁/机械废料拼装”的质感，通过外露的齿轮、拼贴钢板和外凸的红色发光传感器来体现，但必须保持适当的卡通夸张感，严禁展现任何血腥、惊悚或过于恐怖的细节。
- **地图背景**：探索与战斗地图应服务于“探索玩法”。地面不宜过花，应当作为低饱和度的底层舞台，烘托亮色调的战斗单位。

## 2. 颜色体系与色彩规范
为防止同屏发生过饱和的色彩混乱，建立如下标准色彩板规范：
- **主背景色（低饱和舞台）**：深蓝 / 灰黑 / 钢青色。用于表达地下管道、训练场钢板与背景色。
- **主角专属色（高对比突出）**：暖橙色 / 能量亮蓝 / 金色。用于机甲外甲、喵能炮出火口以及强化特效。
- **敌人标识色（高危险警示）**：工业铁灰 / 机械深蓝 / 猩红警示点。特别规定所有敌人的“眼睛”或“发光核心”必须使用红色光源强化。
- **资源点颜色**：青色 / 能量绿。
- **宝箱/补给箱颜色**：暖金色 / 橙色防爆线条。
- **危险警示/血条**：危险警戒圈使用半透明亮橙色，角色危险状态为大红。
- **状态完成反馈**：亮绿 / 金光。

## 3. 视角与比例规范
游戏内探索模式采用**俯视 / 斜俯视 2.5D 场景视角**。
- **单位比例**：
  - 普通敌人尺寸应小于主角，建议为主角视觉尺寸的 `50%～65%`；
  - 精英敌人尺寸应比普通敌人大约 `20%～35%`，建议与主角尺寸基本对齐或略大；
  - 宝箱和资源点在地图上应有夸张的缩放，突出其在地图上的重要程度，不与地砖融为一体。
- **立绘与游戏单位分离**：游戏运行时的 Sprite 图案应当是适合俯视行走和移动的设计，头身比建议为 `1:1.5` 到 `1:2` 的 Q 版比例。

## 4. 线条与细节描边
- **粗线条外边框**：所有战斗单位（主角、敌人）应具有 1~2 像素清晰的深色描边或高亮轮廓，防止其在移动时与地面网格线重叠融合。
- **大体块表现**：小尺寸设备下必须能够清晰辨认每个角色的轮廓特征，不要画过多的细碎排线、微小螺丝等低效细节，而应使用大色块和明显的轮廓变体强化识别度。
- **地图装饰分层**：地图边缘障碍物和装饰物使用低亮度和偏冷的色调处理，拉开空间层次感。
