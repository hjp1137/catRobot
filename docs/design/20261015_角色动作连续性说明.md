# 角色动作连续性调整（2026-10-15）

## 原因与边界

- 英雄原素材：横向 8 帧、每帧 90ms；上下各 6 帧、每帧 90ms。
- 旧实现以角色存活总时间取帧，转向会从 720ms 周期直接跳到 540ms 周期的另一相位。
- 停步强制切第 0 帧；继续移动后又切回全局时间对应帧，产生启停跳姿。
- 原英雄横向图片为 443×443，上下图片为 512×512；有效角色高度分别约 317px 和 420px。
- 旧实现按整张画布宽缩放且以图片中心定位，方向切换造成身体尺寸和脚底位置变化。
- 精英、首领、机械虫、无人机使用独立的生成美术，覆盖动作纹理后只剩一张姿势。
- 精英旧 6 帧素材为像素方头形象，与当前机甲美术不一致，继续保留当前机甲形象。

## 现在的动作逻辑

- `gait_phase` 以实际位移 / 步幅累计，与存活时间分开。
- 碰撞阻止位移时不推进步态；停止时保留当前腿部相位。
- 英雄 150px / 周期，普通敌人 115px / 周期，精英 165px / 周期，首领 210px / 周期。
- 同一 0–1 相位映射各方向原有帧序列，转向不会更换时钟。
- 主方向采用 1.28 / 0.78 的切换滞回，并保持 65ms 的最短方向稳态，避免斜向边缘反复换向。
- 启动约 63ms 达到完整动作强度，停止约 111ms 收回附加摆动，停步不重置到首帧。

## 定位与连续关节

- `actor_motion.json` 保存 60 张现有纹理的有效区域，阈值为 alpha ≥ 40，不修改原图片。
- 英雄按同一方向整组帧的有效身体高度缩放，避免逐帧伸缩。
- 鼠、机械虫和无人机按最大有效轴注册，保留不同透视下的身体体量。
- 脚底锚定角色地面原点，碰撞位置和画面人物落脚点一致；无人机保留18px悬浮。
- 实机贴身画面核查后，运行时物理半径下限设为英雄34、鼠26、虫36、无人机34、精英44、首领65，匹配脚下体积；保留配置中的更大半径，不改角色图像比例。
- `actor_motion_rig.gd` 用一层 16×16 网格绘制单张纹理；尺寸相同的网格在角色间共享。
- 双足机甲分别驱动左右腿、外侧机械臂；机械虫驱动边缘多足；无人机驱动机翼和小幅悬浮。
- 原有真实跑步帧继续展示；网格补充两帧之间的连续关节活动。
- 本次没有虚增原画帧数，没有交叉淡入、混帧或重影。
- Sprite2D 的纹理、朝向和材质接口保留；可见网格同步受击着色及套装着色。

## 验证归属

动作模块提交后由主流程统一执行 Godot 解析、回归和 GPU 连续帧验证，结果见本轮 Walkthroughes 成果说明。
