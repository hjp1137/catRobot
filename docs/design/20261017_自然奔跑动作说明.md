# 自然奔跑动作调整（2026-10-17）

## 查明的问题

- 逐张查看现有横向 8 张、上下各 6 张原画，已经包含抬膝、收腿和手臂变化，不能简单归结为帧数少。
- 原逻辑用实际位移推进步态是正确的，但玩家 150px / 周期配合 340px/s 移速，达到 2.27 个完整左右周期 / 秒，约 4.53 次落脚 / 秒。
- 此时横向每张原画只显示约 55ms，上下每张约 74ms；相近收腿姿势快速反复，容易显得碎步。
- 每帧最低脚被注册到同一地面，附加肢端动作仅约 1px，上身缺少与迈步配合的前倾和肩髋协调。
- 原画本身已经有头部高度变化，因此额外大幅跳动或形变会破坏机甲的重量感。

## 本轮实现

- 玩家步距改为 250px / 完整左右周期：340 移速时为 1.36 周期 / 秒，约 2.72 次落脚 / 秒。
- 横向 8 帧每张约 92ms，上下各 6 帧每张约 123ms；素材数量仍然为 8 / 6 / 6，没有重复帧充数。
- 网格维持单层纹理和原有 16×16 分区，原画负责大姿势，连续网格只补充肢端的细小动势。
- 玩家肢端变形强度由 0.008 调到 0.020；横向脚部最大约 2.5px，正背面横移进一步收窄，避免横向扭腿。
- 肩部和髋部增加小于 1px 的相反摆动，手臂配合腿部反向运动；头盔区域不单独弯曲。
- 侧向奔跑整体平滑前倾最多 1.1°，叠加最多 0.28° 的周期协调；前倾随朝向平滑变化。
- 每个完整周期有两次最多 2px 的短暂腾空，地面原点、碰撞圆和真实位置保持不变。
- 停止或撞住时相位不再推进；附加摆动和腾空随原有动作强度收回，整体前倾平滑归零，不原地继续跑。
- 转向依旧沿用同一相位和现有方向滞回，未切换到其他角色造型的待机图。

## 保留的行为与取舍

- 340 移速、角色体量、碰撞半径、敌人动作参数、伤害和所有装备着色均保持。
- 不恢复人物脚圈、寻路线或目标圈，不使用残影、混帧或交叉淡入。
- 原画帧仍是离散姿势；本轮调整针对频率、支撑/腾空和上身协调，并不声称重绘了完整高帧率骨骼动画。
- 额外升降和前倾保持克制，避免机甲像软体一样弯曲，或角色画面与真实碰撞位置明显分离。

## 验证归属

动作模块不单独并发启动 Godot。由主流程统一执行解析、步距/启停/转向专项与 GPU 连续帧核查；验证结论记录到本轮 Walkthroughes 成果说明。
