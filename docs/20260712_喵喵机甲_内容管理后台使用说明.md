# 喵喵机甲内容管理后台使用说明

## 1. 环境要求

- Node.js：22.18 兼容版本；当前本机验证版本为 Node.js 24.14.1。
- 后端：NestJS 11、Prisma 6.19.0、MySQL 8.0.33。
- 管理端：Vben Admin 5.7.0 目标目录形态，Vue 3、Vite、TypeScript、Ant Design Vue、Pinia、Vue Router。
- 包管理：根项目使用 npm，管理端使用 pnpm 10.33.0。

## 2. 数据库配置

复制 `server/.env.example` 为 `server/.env`，填入：

```env
DATABASE_URL=mysql://用户名:密码@远程地址:3306/cat_robot?connection_limit=1&pool_timeout=10
JWT_SECRET=至少32位随机字符串
CAT_ROBOT_PROJECT_ROOT=..
```

真实数据库密码不得写入代码、文档或 Git。

## 3. migration

先执行只读检查：

```bash
npm run content:db:status
curl http://127.0.0.1:3100/api/health/database
```

确认目标库是 `cat_robot` 且 MySQL 为 8.0.33 后执行：

```bash
npm run content:db:migrate
```

## 4. Seed 与 Art Manifest

```bash
npm run content:db:seed
npm run content:art:sync
```

Seed 已有 ID 只跳过，不覆盖，不删除远程数据。

## 5. 创建管理员

```bash
npm --prefix server run content:admin:create-user -- admin_user 强密码 admin
```

不提供注册、找回密码或默认硬编码密码。

## 6. 启动

```bash
npm run content:server
pnpm --dir admin/apps/web-antd dev
```

后端默认 `127.0.0.1:3100`，管理端默认 `127.0.0.1:5602`。

## 7. 内容管理

- 敌人管理：新增、编辑、复制、启用、禁用、删除、引用查看。
- 背景管理：维护背景 Art Key、渲染配置、颜色配置和引用关系。
- 主角管理：维护主角动作 Art Key、技能图标和表现参数。
- 关卡管理：维护固定屏波次、自由探索刷新组、目标和模板绑定。
- 美术资源：从 Art Manifest 同步，任务22不提供上传。

## 8. Art Key选择

管理端公共 `ArtResourceSelector` 从 `/api/content/resources` 加载资源，过滤 Missing 状态，不允许填写任意物理路径。

## 9. 校验、发布和恢复

在“校验与发布”页面执行完整校验。校验通过后发布生成：

```text
src/content/generated/contentSnapshot.ts
content-store/published/content.snapshot.json
```

历史版本恢复只恢复为草稿，需要再次校验和发布才进入游戏。

## 10. 游戏构建

发布成功后执行：

```bash
npm run check:content
npm run build
```

微信小游戏只读取生成快照或内置默认配置，不访问后台 API 或 MySQL。

## 11. 常见问题

- `DATABASE_URL` 缺失：只能运行非数据库测试，不能执行 migrate/seed/publish。
- 发布包校验变慢：确认 `project.config.json` 已忽略 `server/`、`admin/`、`packages/`。
- 发布失败：旧快照文件不应被覆盖，查看 `content_release.failure_reason`。
